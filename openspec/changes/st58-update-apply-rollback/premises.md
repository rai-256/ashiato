# ST58 の前提（外の形式・振る舞い）

問いを立てる前に確かめたもの。確かさは story-upstream の 1〜5（1 言っただけ / 2 出所を示した / 3 辿った / 4 走らせた / 5 実物で再現した）。
2026-11-15 に確かめた。

**失われるもの（`loss`）のある問いは Q1（PC の入れ方: `uncaptured`）・Q5（途中で止まる: `discarded`）・Q6（「戻した」の形: `rewrite-all`）・Q7（退避の保持: `discarded`）。**
Q1 の推奨の手順は、spec の段で動いている実行ファイルの名前を変えない形（design D12（仮）。版ごとの置き場から起こす）にしたので P4 に依らない（review/spec.md R12）。P4 は D12（仮）の反転条件の先として残す。
Q5〜Q7 は repo の実物（確かさ 3）に載る。携帯の更新の後の再開（defaults.md P1 → 第 2 回の Q8・design D10）が依る P6・P7 は、Task 9.2 のエミュレータ段で確かめて確かさ 4 に上げた。
