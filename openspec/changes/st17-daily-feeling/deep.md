|---|---|---|---|
| C1 | 快–不快の見分け方 | **数値（-2〜+2）と言葉で出し、色で分けない** | NFR-23（意味を担う非テキストは隣と 3:1）。5 段を隣接 3:1 で並べるには 3⁴ = 81:1 が要り、sRGB の最大 21:1 を超える（ST02 の格子と同じ計算） |
| C2 | 書き直し | **書くたびに新しい記録として積み、前の記録を書き換えない。** DB の錠で、主観の行の書き換えと行の削除を拒む（消すのは FR-50 / FR-51 の経路だけ）。原文に記録ごとの識別子と、**他の列へ写さない 128 bit の乱数**を入れ、内容で畳まない（同じ値をもう一度書いても 1 件増える）。乱数が無いと、快–不快は 5 値しか無いので、本文を消した（FR-51）後に残る `id`・出来事の時刻・内容の鍵から値を総当たりで当て直せる（ST19 の C12 / D4 と同じ。**R2**。最初の行が入る前に決める —— 後から鍵の入力を変えると凍結した全行の作り直し） | 台帳は追記のみ / 既定は厳しい側。前の答えは後から作れない（`discarded`）。ST19 の主張（C1 / C2）と同じ形 |
| C3 | 時刻 | **記入の日時**（タイムゾーンも）と**対象**（日なら Asia/Tokyo で区切った日付、滞在ならその識別子と書いた時点の始まり・終わり）を別々に持つ。時刻を日に丸めない。**どちらを全記録の「出来事の時刻」の列に入れるかは Q12**（**R1** で C から外した） | FR-41。細かい粒度で持つ。前/後（Q5）を時刻から何度でも計算し直せる |
| C4 | 尺度の器 | 尺度は（識別子・版・値）の組の並び。快–不快も識別子 `valence`・版 1 の尺度として同じ形で持ち、**必須の検査を掛ける**（-2〜+2 の整数、無ければ断る） | FR-36 / FR-40。快–不快だけ別の列にすると、版を上げる（言葉を変える）ときに別の扱いが要る |
| C5 | 紐づけ先 | **種類の登録簿**（day one は「日」と「滞在」の 2 行）と、（種類・鍵）の参照。滞在の鍵は滞在の識別子（FR-31 で作り直しでも保たれる） | 扉 #2 の決着どおり。鍵ではなく索引（鍵を外部キーで縛らない —— 新しい種類を足すとき既存の行に触れない。FR-38） |
| C6 | 感度 | 取り込みで「**ローカル AI まで**」を付ける | PERM-4。DB の既定（外部 AI 可）に黙って乗らない（ST19 と同じ） |
| C7 | 由来とソース | 「本人が書いた」（FR-25）。論理ソースを登録簿に 1 行。**途絶の通知（FR-35）の対象にしない**（書かない日は壊れていない） | 書かない日は「未記入」として FR-57 で見える。途絶として鳴らすと二重 |
