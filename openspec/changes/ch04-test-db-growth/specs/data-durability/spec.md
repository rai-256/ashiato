## ADDED Requirements

### Requirement: 書き出しから除く範囲の判定は、記録の行数と消した滞在の数を一緒に伸ばしても、その積で伸びない

THE SYSTEM SHALL 書き出しから除く範囲の判定（書き出しの本体・設定画面の件数の数え・後に消した記録の件数が同じ判定を通る）で、
記録と前の版の 1 行ごとに消した時間の一覧の全部を読み直さない。記録の行数 N と消した滞在の数 M を一緒に k 倍にしたとき、判定が消した時間の一覧から読む量は k の 2 乗でなく k の桁で伸びる。
どの記録と前の版を除くかは、この Requirement を足す前の判定と 1 件も変えない（消した時間と幅の重なりは、両端を含む閉じた区間どうしの重なりのまま。終わりが始まりより前の消した時間・
終わりが記録の時刻より前の幅・内容に終わりを持たない消した滞在と前の版も、足す前と同じに読む）。件数の数え方は変えない。
導出元: CH04

#### Scenario: 記録と消した滞在を一緒に 4 倍にしても、消した時間を読む量は 4 倍の桁に収まる
- **WHEN** まっさらな database に、消した滞在 M = 10 件と、緯度経度つきの記録 N = 1,000 件（消した時間をまたぐものと、どの消した時間にも重ならないものを混ぜる）を置いて除く範囲の判定の計画と実行を読み、M = 40・N = 4,000 でも同じことをする
- **THEN** 消した時間の一覧を読む節で読んだ行の数（返した行と条件で捨てた行の和に、繰り返しの回数を掛けたもの）の和は、4 倍の量で 1 倍の量の 8 倍未満である
- **AND** 同じ材料に、この Requirement を足す前の判定を当てると 8 倍以上である

#### Scenario: 直した判定は、足す前の判定と同じ記録と前の版を除く
- **WHEN** まっさらな database に、消した時間の端にちょうど触れる・中に入る・外れる記録、終わりが始まりより前の消した時間、内容に終わりを持たない消した滞在（終わりは始まりの 1 µs 後として読む）と前の版（終わりは前の版の時刻）、幅の終わりが記録の時刻より前の記録、重なり合う消した時間と隣り合う消した時間、前の版を置き、直した判定と、最後の重なりの条件だけを足す前の形に戻した判定を、同じ時点で走らせる
- **THEN** 除く記録の id の集まりと、除く前の版の id の集まりが、それぞれ一致する

#### Scenario: 記録の行数と消した滞在の数を一緒に倍にした 3 通りで、書き出しと件数の数えの時間を測って残す
- **WHEN** (N, M) = (30 万, 25)・(60 万, 50)・(120 万, 100) の 3 通りを、それぞれ試験ごとの database で書き出しと件数の数えにかける
- **THEN** 3 通りの書き出しの時間と件数の数えの時間と、隣り合う組の比を出力する
