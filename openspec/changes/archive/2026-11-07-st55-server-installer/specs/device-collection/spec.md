## MODIFIED Requirements

### Requirement: D-02 の置き場は設定で変えられ、撮影の年/月のフォルダに撮影日時と元の名前で並ぶ

THE SYSTEM SHALL D-02 の置き場を設定で変えられるようにし、インストールした形（サービスの口）でなく動く S-01 で設定が無ければ `%LOCALAPPDATA%\ashiato\media`（それが無い環境ではユーザーのデータの置き場の `ashiato/media`）にする。
WHEN S-01 がインストールした形（サービス）で動き、置き場の設定が無い THE SYSTEM SHALL D-02 の置き場を、状態の置き場（Windows では `C:\ProgramData\ashiato`）の下の `media` にする。
IF 設定された置き場が絶対の場所でない THEN THE SYSTEM SHALL S-01 を起動せず、設定の名前を挙げて終える。
WHEN S-01 が起動する THE SYSTEM SHALL 既定の置き場が無ければ作る。
THE SYSTEM SHALL 設定された置き場が無いとき、作らずに、原本を書けない失敗として扱う（外したドライブの空の差し込み口に書かない）。
THE SYSTEM SHALL 原本を、置き場の下の撮影の年/月のフォルダ（記録の出来事の時刻を記録の地域で読んだもの）に、`<撮影日時>_<元のファイル名>` の名前で置く。
IF 同じ名前のファイルが中身の違うものとしてすでにある THEN THE SYSTEM SHALL 名前の末尾（拡張子の前）に内容ハッシュの頭を足して置く。
THE SYSTEM SHALL 元のファイル名に置き場の区切りや使えない文字があっても、置き場の外に書かない。

導出元: FR-4。扉 #20。深掘り Q12（B。本人が選んだ）/ C10。
★ ST55（FR-109・申し送り C6）: インストールした形では S-01 がサービスのアカウントで動き、`%LOCALAPPDATA%` はサービスのプロファイルを指す。原本は状態の置き場に置く（本人は読める）。開発の台本で起こす S-01 の既定は変えない。
並びは内容ハッシュとメタから作る規則なので、並びを変えても記録は書き換えない（C2）。

#### Scenario: 原本は撮影の年/月のフォルダに撮影日時と元の名前で置かれる

- **WHEN** 撮影時刻が `2026-10-17T14:30:12+09:00`、元のファイル名が `PXL_20261017_053012345.jpg` の写真の原本が届く
- **THEN** 置き場の下の `2026/10/20261017-143012_PXL_20261017_053012345.jpg` にファイルが置かれる

#### Scenario: 同じ名前の別の中身にはハッシュの頭が足される

- **WHEN** 撮影日時と元のファイル名が同じで中身の違う写真の原本が 2 つ届く
- **THEN** 2 つ目のファイルの名前は、拡張子の前に内容ハッシュの頭を持ち、2 つとも置き場にある

#### Scenario: 元の名前に区切りがあっても置き場の外に書かない

- **WHEN** 元のファイル名が `..\..\evil.jpg` の写真の原本が届く
- **THEN** ファイルは置き場の下の撮影の年/月のフォルダにだけ置かれ、置き場の外には何も書かれない

#### Scenario: 置き場の設定が無ければ既定の置き場になる

- **WHEN** 開発の台本で（サービスの口でなく）置き場の設定が無い状態で S-01 を起動する
- **THEN** D-02 の置き場は `%LOCALAPPDATA%\ashiato\media`（それが無い環境ではユーザーのデータの置き場の `ashiato/media`）である

#### Scenario: 置き場を設定で変えられる

- **WHEN** 置き場の設定に別のドライブの絶対の場所を入れて S-01 を起動し、写真の原本が届く
- **THEN** 原本はその置き場の下に置かれる

#### Scenario: 設定した置き場が無ければ作らずに書けない失敗にする

- **WHEN** 置き場の設定に、まだ無い絶対の場所を入れて S-01 を起動し、写真の原本を送る
- **THEN** その場所は作られず、後で送り直せる失敗が返る

#### Scenario: 相対の置き場では起動しない

- **WHEN** 置き場の設定に相対の場所を入れて S-01 を起動する
- **THEN** S-01 は起動せず、置き場の設定の名前を挙げて終える

#### Scenario: インストールした形では、設定が無ければ状態の置き場の media に置く

- **WHEN** 置き場の設定が無いインストールした形の S-01 に、写真の原本が届く
- **THEN** 原本は `C:\ProgramData\ashiato\media` の下の撮影の年/月のフォルダに置かれ、サービスのアカウントのプロファイルの下には何も置かれない
