問いを立てる前に確かめたもの。確かさは story-upstream の 1〜5（1 言っただけ / 2 出所を示した / 3 辿った / 4 走らせた / 5 実物で再現した）。
2026-11-03 の要件の改訂（同梱の PostgreSQL・Windows のサービス・`ProgramData`）で立て直した版。Docker 前提の旧い版は commit `4f068c66` にある。

## 触らなかったもの

- Windows の上で、同梱する PostgreSQL の `initdb.exe` を走らせること（P3・P4 の Windows の側）。落とした実行ファイルを動かすのは、このセッションの権限で断られた。tasks の Windows の CI で走らせる
- サービスのアカウント（仮想アカウント `NT SERVICE\…`）で動かしたときの `USERPROFILE` / `LOCALAPPDATA` の行き先（P11）。どちらにしてもインストーラが絶対の場所を渡す（C9）ので、問いは依らない
- 同梱する部品（EDB の zip の DLL）の許諾の一覧（監査 C12）。zip の目録は読んだが、許諾の文は読んでいない。tasks で `THIRD-PARTY-NOTICES.txt` に足す
