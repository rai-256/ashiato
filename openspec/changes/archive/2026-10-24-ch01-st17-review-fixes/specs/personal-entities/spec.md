## MODIFIED Requirements

### Requirement: 形の合わない主張は受け付けない

THE SYSTEM SHALL 次の表のいずれかに当たる主張を、その 1 件だけ受け付けず、表の理由の種別を返す。

| 理由の種別 | 当たるもの |
|---|---|
| `malformed_claim` | 原文が JSON でない / 必須の欄が欠ける / 原文の主張の識別子が記録の識別子と違う / 原文の乱数が 128 bit に満たない / 地域のずれが -1,439〜+1,439 分の外 |
| `claim_not_authored` | 由来が「本人が書いた」でない / 端末識別子を持つ |
| `claim_has_external_id` | 外部サービス上の識別子か対象の識別子を持つ |
| `unknown_attribute_kind` | その利用者に無い種類 |
| `invalid_claim_value` | 値が、前後の空白を除いて空で、「なし」でもない |
| `invalid_valid_from` | 精度と日付の形が合わない / 暦に無い日付 |
| `invalid_supersedes` | 取り消す主張が無い / 個人属性の主張でない / 別の利用者 / 別の種類 / 自分自身 |

THE SYSTEM SHALL 削除の印の付いた主張や本文を消去した主張を取り消し先に指す主張を、その理由では断らない。
THE SYSTEM SHALL 1 つの主張を複数の主張が取り消すことを、その理由では断らない。
THE SYSTEM SHALL 主張を受け付けなかった応答に、主張の値・補足を含めない。
THE SYSTEM SHALL 原文の形 → 由来と端末識別子（`claim_not_authored`）→ 外部識別子（`claim_has_external_id`）→ 地域のずれの範囲（`malformed_claim`）→ 表の残りの行 の順に確かめ、2 つ以上に当たる主張には、最初に当たったものの種別を返す。
THE SYSTEM SHALL 主張の地域を `Asia/Tokyo` に限らない（地域のずれが範囲の中なら、その理由では断らない）。

導出元: FR-44, FR-45, FR-23, FR-25。深掘り C5 / C7 / C12。design D5。
取り消す主張の検査が無いと、別の種類の主張を取り消して「いまの値」が黙って変わる。
由来を見ないと、「派生させた」や「収集した」として入った主張に、主張の錠ではなく別の規則が掛かる。
消した主張を取り消し先に指しても、読み出しがその取り消しを効かせる相手はいない（「種類ごとのいまの値と履歴を読める」）ので害が無い。
CH01（深掘り Q7。design D7（仮））: いまの取り込みの振る舞いを固定する。人が書いた記録の規則（主張・主観・場所）を 1 つにまとめても、理由の種別と順が変わらないことをここで見る。地域のずれの範囲を断るのは、範囲の外の値が受理された顔で格納され読み出しから消えるから。主観の記録の地域が `Asia/Tokyo` に限られるのは `subjective-log` の決定で、ここと違ってよい。

### Requirement: 形の合わない場所の記録は受け付けない

THE SYSTEM SHALL 次の表のいずれかに当たる場所の記録を、その 1 件だけ受け付けず、表の理由の種別を返す。

| 理由の種別 | 当たるもの |
|---|---|
| `malformed_place_record` | 原文が JSON でない / 場所・記録の識別子・乱数・何を書くものか・その値の欄が欠ける / 欄の型が違う / 何を書くものか（名前・座標・広さ・補足）が分からない / 原文の記録の識別子が記録の識別子と違う / 原文の乱数が 128 bit に満たない / 地域のずれが -1,439〜+1,439 分の外 |
| `place_record_not_authored` | 由来が「本人が書いた」でない / 端末識別子を持つ |
| `place_record_has_external_id` | 外部サービス上の識別子か対象の識別子を持つ |
| `unknown_place` | 指す器がその利用者に無い |
| `invalid_place_name` | 名前が、前後の空白を除いて空 |
| `invalid_coordinate` | 緯度が -90〜90 の外 / 経度が -180〜180 の外 / 数でない / 座標系が WGS84（`EPSG:4326`）でない |
| `invalid_coord_change` | 変え方が「初めての座標」「間違いを直す」「移った」のどれでもない / 「初めての座標」なのにその場所が既に座標の記録を持つ / 「移った」なのにその場所が座標の記録を持たない / 「間違いを直す」なのに直す先の欄が空 / 「移った」なのに「いつから」の欄が空 / 「初めての座標」か「間違いを直す」なのに「いつから」の欄を持つ / 「初めての座標」か「移った」なのに直す先の欄を持つ |
| `invalid_valid_from` | 精度と日付の形が合わない / 暦に無い日付 |
| `invalid_coord_supersedes` | 直す先の欄が指す記録が無い / 座標の記録でない / 別の場所の記録 / 別の利用者 / 自分自身 |
| `invalid_radius` | 広さが整数でない / 10 m より小さい / 5,000 m より大きい |

THE SYSTEM SHALL 削除の印の付いた座標の記録や本文を消去した座標の記録を直す先に指す記録を、その理由では断らない。
THE SYSTEM SHALL 「座標の記録を持つ」に、削除の印の付いた座標の記録と本文を消去した座標の記録も数える。
THE SYSTEM SHALL 場所の記録を受け付けなかった応答に、名前・補足・座標の値を含めない。
THE SYSTEM SHALL 原文の形 → 由来と端末識別子（`place_record_not_authored`）→ 外部識別子（`place_record_has_external_id`）→ 地域のずれの範囲（`malformed_place_record`）→ 表の残りの行 の順に確かめ、2 つ以上に当たる場所の記録には、最初に当たったものの種別を返す。
THE SYSTEM SHALL 場所の記録の地域を `Asia/Tokyo` に限らない（地域のずれが範囲の中なら、その理由では断らない）。

導出元: FR-48, FR-49, FR-23, FR-25, FR-27, FR-28。深掘り Q2 / C3 / C7 / C11。design D2 / D4（仮）。
直す先の検査が無いと、別の場所の座標を直して、その場所の照合が黙って変わる。
「移った」が座標を持たない場所に入ると、移る前が無いのに前の期間が切れる。
CH01（深掘り Q7。design D7（仮））: いまの取り込みの振る舞いを固定する。人が書いた記録の規則（主張・主観・場所）を 1 つにまとめても、理由の種別と順が変わらないことをここで見る。地域のずれの範囲を断るのは、範囲の外の値が受理された顔で格納され読み出しから消えるから。主観の記録の地域が `Asia/Tokyo` に限られるのは `subjective-log` の決定で、ここと違ってよい。
