## MODIFIED Requirements

### Requirement: 本文ごと消す範囲は、消したときに一緒に消えた記録と、その時間に重なる滞在と、それぞれの前の版すべて

WHEN 本人が消した滞在を本文ごと消す THE SYSTEM SHALL 次の記録の本文を、それぞれの前の版すべての本文とともに消去する:
その滞在 / その滞在を原因として削除の印が付いた記録（位置・書庫の位置・位置を持つ書庫の項目。消した後に届いて印が付いた分を含む）/
その滞在の時間と重なる滞在のうち、作り直しが付けた印を持つもの（作り直しで吸収された滞在と、消した時間帯と重なって隠された滞在）。
THE SYSTEM SHALL 写真・動画・スクリーンショット・画像の記録と、PC のウィンドウ・ブラウザ履歴の記録の本文を消さない。
THE SYSTEM SHALL その滞在を指して書いた気分の記録の本文を消さない。
THE SYSTEM SHALL 本人が別の操作で消した記録（原因が別の滞在の記録）の本文を、この操作では消さない。
THE SYSTEM SHALL この操作では、本人が別の操作で消した滞在と、削除の印の無い滞在（一覧に出ている滞在）の本文を、時間が重なっていても消さない
（削除の印の無い滞在が後で作り直しで隠れたときは「本文を消した記録は戻せず、作り直しも戻さない」に従う）。
THE SYSTEM SHALL 端が触れるだけで時間が重ならない滞在を、重なる滞在に含めない。

導出元: FR-51（「消去は履歴に残した前の版にも及ぶ」）, FR-50。深掘り Q2（推奨。`loss: discarded`）/ C8 / C14。spec のレビュー R2 / R5（失わない側に倒した仮。design D2 / D17）。申し送り `docs/handoff/ST23.md` の st16 R38・2026-10-12-st12-consistency C3 / C4。
位置だけを消しても、滞在とその前の版が重心の緯度経度を持ち続ける（ST16 の実測）。
CH08 の spec review R10（一覧に出ている滞在を消さないのは、この操作の時点に限る）。

- **THEN** その滞在と 3 件の位置の記録の本文（原文と解析済み）はどれも空になっている

### Requirement: 消したものを戻せる

WHEN 資格情報を持つ呼び出し元が 1 件以上の滞在の識別子を指定して戻すことを求める THE SYSTEM SHALL その滞在の削除済みの印と削除時刻を外し、
**同じ滞在を原因として消えた位置の記録**（消した後に届いて印を付けて入った分を含む）の印も外し、その日の滞在を作り直す。
THE SYSTEM SHALL 戻した時間帯に、消した時間帯と重なって隠されていた滞在があれば、作り直しによって読み出しに戻す。
THE SYSTEM SHALL 別の操作で消えた記録は戻さない。
THE SYSTEM SHALL 消えていない滞在を戻す求めを、戻した件数 0 とともに 200 で返す。
THE SYSTEM SHALL 資格情報の無い求めを 401 で、存在しない識別子を 404 で断る。
THE SYSTEM SHALL 戻すことになる記録（指定した滞在と、それを原因として消えた記録のうち、別の原因で消えたままにならないもの）に本文を消した記録が 1 件でもあれば、何も戻さずに 409 で断る。
THE SYSTEM SHALL 別の原因（本文ごと消した滞在を含む）で消えたままになる記録は、その数に入れない（戻さずに残す。いまの「別の操作で消えた記録は戻さない」と同じ）。
THE SYSTEM SHALL 指定した滞在に、本文ごと消した時間帯と時間が重なる（端が触れるだけは含めない）ものがあり、戻した後の作り直しでその滞在が読み出しに戻らない
（本文ごと消した時間帯にすっぽり入る・はみ出した分が滞在にならない・吸収される）ときは、何も戻さず、作り直しもせずに 409 で断り、本文を消した記録を含むときの断りと区別できる理由を返す。
その滞在は「消した」のまま残り、その本文も消さない。
THE SYSTEM SHALL 本文ごと消した時間帯と重ならない滞在と、戻した後に読み出しに戻る滞在は、いまのとおり戻す。
THE SYSTEM SHALL 本文ごと消した時間帯と重なる滞在を戻すかを確かめる作り直しが失敗したときは、何も戻さずに 503 で断る（もう一度求めれば同じ確かめをやり直す）。

導出元: FR-50（★ 2026-09-15 / ★ 2026-10-23「本文ごと消した時間帯は『戻す』の対象にならない」）, FR-51。深掘り Q4（本人の決定）。申し送り `docs/handoff/ST22.md` R19 の後段。ST23 の深掘り C2（本文を消した記録は戻らない）。
CH08 の深掘り Q2（本人の決定。`loss: discarded`）。戻しても一覧に戻らない滞在を戻すと、次の作り直しで隠れてその本文が確認なしに消える（下の「本文を消した記録は戻せず、作り直しも戻さない」）。

### Requirement: 「消した」の行から戻せる

THE SYSTEM SHALL 1 日の一覧の「消した」の行に「戻す」の操作を置く。
THE SYSTEM SHALL 「戻す」を押したとき、その行が表す消した滞在をすべて戻し、一覧を読み直す。
THE SYSTEM SHALL 「消した」の行に、「戻す」と並べて「本文ごと消す」を置く（`record-deletion`「「消した」の行から本文ごと消せる」）。
THE SYSTEM SHALL 「本文ごと消した」の行には「戻す」を置かない。
THE SYSTEM SHALL 本文ごと消した時間にすっぽり入る消した滞在の行（`browsing-views`「日付を指定するとその日の滞在が時刻順に一覧で出る」の、「本文ごと消した」の行の下の行）には「戻す」を置かず、
「本文ごと消した時間の中なので戻せません」と添える。
THE SYSTEM SHALL 「戻す」が戻しても一覧に戻らないことを理由に断られたときは、その行に戻せなかったことを出し、行を「消した」のまま残す。

導出元: FR-50（★ 2026-09-15 / ★ 2026-10-23）, FR-51。深掘り Q4（本人が proto の初期値から動かした軸）。ST23 の深掘り Q5（推奨の形）/ C2。
CH08 の深掘り Q2（本人の決定。ST23 の深掘り第 2 回 Q7 の「B の行に『戻す』を出す」を、すっぽり入る消した滞在について覆した）。
戻す操作は失われるものを作らないので、消すときと違って確認を挟まない。

- **THEN** その時間に滞在の行が戻り、「消した」の行は消える

- **THEN** その行に戻せなかったことが出て、「消した 11:00 – 11:05」の行は「戻す」を持ったまま残り、滞在の行は増えていない

### Requirement: 本文ごと消す前に、消える件数と残るものを示す

WHEN 資格情報を持つ呼び出し元が、本人が消した滞在の識別子を指定して本文ごと消す前の確認を求める THE SYSTEM SHALL 何も書き換えずに、
本文ごと消す範囲の件数を**ソースの組ごと**（滞在・位置・書庫の位置・書庫の項目）と、**前の版の件数**に分けて返す。
THE SYSTEM SHALL あわせて、消えずに残るもの —— 範囲の記録が入っている可能性のある、残している書庫の写しの数・本人のフォルダの書庫・書き出したファイル・
DB のファイルに残る痕跡が次の書き直し（毎晩 3:30）まで残ること —— を返す。
THE SYSTEM SHALL 書庫の写しの数を少なく数えない（写しの中の 1 件を特定できないときは、その記録のソースを読んだ写しを数える）。
THE SYSTEM SHALL 確認を求める口でも、消す口と同じ条件（消えていない滞在は 409、滞在でない・存在しない識別子は 404、資格情報の無い求めは 401）で断る。
THE SYSTEM SHALL すでに本文ごと消した滞在の確認には、件数をすべて 0 とし、本文ごと消したことを添えて 200 で返す。
THE SYSTEM SHALL あわせて、指定した滞在の時間と重なる（端が触れるだけは含めない）、一覧に出ている滞在（削除の印の無い滞在）の件数を、消える件数とは別に返す。その滞在を消える件数に入れず、本文ごと消す範囲も変えない。
THE SYSTEM SHALL 消す口では、確認の後にその件数が変わっていても断らない（その滞在は消さないので、確認で見せた消える件数は変わらない）。

導出元: FR-52（★ 2026-10-24 補足）。深掘り Q5（推奨の形: ソースごと＋前の版＋消えずに残るもの）/ Q4（推奨: 写しは消さない）/ Q6（推奨: 毎晩の書き直し）/ C10。
CH08 の深掘り Q4（本人の決定。一覧に出ている重なる滞在は、後で作り直しで隠れたら本文が消える —— 「本文を消した記録は戻せず、作り直しも戻さない」）。
戻せない操作なので、見せる件数は消す口が実際に消す範囲と同じ数え方で数える。

- **WHEN** 滞在の詳細の「この滞在を消す」を押す
- **THEN** 確認の文面は一緒に消える位置の件数だけを出し、「消す」と「やめる」を置く（ST22 と同じ）

## ADDED Requirements

### Requirement: 本文ごと消した後に作り直しで隠れたのに本文が残る重なる滞在は、サーバの起動のたびに本文を消す

WHEN サーバが起動する THE SYSTEM SHALL いまの時間（作り直しの印で隠れたときの時間）が本文ごと消した時間帯と重なり（端が触れるだけは含めない）、その本文ごと消す操作の時点では一覧に出ていて、その後に作り直しの印で隠れたのに本文が残っている滞在を探し、
「本文を消した記録は戻せず、作り直しも戻さない」の作り直しで隠れた重なる滞在と同じ形で、本文と前の版すべての本文を消去し、後から本文を消した操作として台帳に残す。
THE SYSTEM SHALL 本文ごと消す操作の前から作り直しの印で隠れていた滞在と、本文ごと消した後に作り直しが新しく作って初めから隠した滞在と、本人が消したことのある滞在（戻した後に作り直しで隠れたものを含む）の本文を、この手当てで消さない。
THE SYSTEM SHALL 何度起動しても、本文を消す記録と台帳の行を増やさない。対象が無ければ何も書かない。
THE SYSTEM SHALL 手当てが失敗しても起動を止めず、消せずに残った件数をログに出し（記録の識別子・時刻・本文は出さない）、次の起動で消し直す。

導出元: FR-50（★ 2026-10-23）, FR-51。CH08 の深掘り Q5（本人の決定: サーバの起動のたびに、Q8 と同じ処理で探して消す）/ C1 / C2。
ST23 は「作り直しで隠れた重なる滞在の本文も消す」を含まずに main へ入ったので、その間に隠れた滞在は消した場面の座標を持ったまま、どの口からも消せない。

#### Scenario: 起動すると本文ごと消した後に隠れて本文が残った重なる滞在の本文が消える

- **WHEN** 10:00 から 11:00 の滞在を本文ごと消した後に、一覧に出ていた重なる 10:30 から 11:30 の滞在（前の版 2 件）が本文を残したまま作り直しで隠れた状態で、サーバを起動する
- **THEN** 10:30 から 11:30 の滞在とその 2 件の前の版の本文は空で、元の操作に結ばれた後からの操作の行（滞在の件数 1）と、その滞在の時間の範囲の行がある

#### Scenario: 起動を繰り返しても台帳の行は増えない

- **WHEN** 本文ごと消した後に隠れて本文が残った重なる滞在がある状態で、サーバを 2 回起動する
- **THEN** 2 回目の起動の後の消去の操作の台帳と記録ごとの消去の台帳の行の数は、1 回目の起動の後と同じである

#### Scenario: 本文ごと消す前から隠れていた端の滞在は起動しても本文が残る

- **WHEN** 10:00 から 11:00 の滞在を消し、11:00 から 12:00 の滞在が作り直しの印で隠れた後に 10:00 から 11:00 の滞在を本文ごと消した状態で、サーバを起動する
- **THEN** 11:00 から 12:00 の滞在の本文は残っている

#### Scenario: 本文ごと消した後に初めから隠して作られた滞在は起動しても本文が残る

- **WHEN** 10:00 から 11:00 の滞在を本文ごと消した後に、作り直しがその時間帯と重なる新しい滞在を初めから隠して作った状態で、サーバを起動する
- **THEN** その新しい滞在の本文は残っている

#### Scenario: 本文ごと消した後に戻されて作り直しで隠れた消した滞在は起動しても本文が残る

- **WHEN** 10:15 から 10:45 の滞在を消し、10:00 から 11:00 の滞在を消して本文ごと消した後に、10:15 から 10:45 の滞在が戻されて作り直しで吸収された状態で、サーバを起動する
- **THEN** 10:15 から 10:45 の滞在の本文は残っている

#### Scenario: 起動の手当てのログは件数だけを持つ

- **WHEN** 手当ての消去が失敗するようにしてサーバを起動する
- **THEN** 手当てのログの行は残った件数を持ち、滞在の識別子と時刻と緯度経度を持たない

#### Scenario: 対象が無ければ起動の手当ては何も書かない

- **WHEN** 本文ごと消した後に隠れて本文が残った重なる滞在が無い状態で、サーバを起動する
- **THEN** 起動の前後で消去の操作の台帳・記録ごとの消去の台帳・削除の台帳の行の数は変わらない

#### Scenario: 手当てが失敗しても起動は止まらず、次の起動で消える

- **WHEN** 本文ごと消した後に隠れて本文が残った重なる滞在がある状態で、手当ての消去が失敗するようにしてサーバを起動し、その後ふつうに起動し直す
- **THEN** 1 回目の起動は止まらず、消せずに残った件数 1 がログに出て、2 回目の起動の後はその滞在の本文が空である
