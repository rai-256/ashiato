## Why

**ST23 は、本人が深掘り第 2 回で決めた Q7・Q8 を含まないまま merge する**（ST23 深掘り第 3 回 Q9。2026-10-28）。ST23 の code-verify（`openspec/changes/st23-record-erasure/review/code.md` R15）は、
使い捨ての DB で次の 2 つを確かめた:

1. **Q7**: 本人が別に「消した」にした滞在 B が、本文ごと消した滞在 P の時間にすっぽり入ると、1 日の一覧は B の区間を差し引いて空にし、B の行を出さない。
   B を戻す口も本文ごと消す口も画面に無く、B の本文（P の場面の座標）が残り続ける（ST23 design D2 の「Q7 待ち」）
2. **Q8**: P を本文ごと消した後、作り直しが P と重なる滞在 L を隠すと、L の本文と前の版が残る。一覧・消す口・本文ごと消す口のどれからも消せない（ST23 design D17 の「Q8 待ち」）。
   FR-50 ★ 2026-10-23 は「隠した同じまとまりで L の本文も消す」と決めている

いま作る理由: ST23 が merge すると、作り直しのたびに 2 の L が DB に溜まる。この change の前に隠れた L は、手当てで後から消す必要がある。

## What Changes

深掘り第 1 回（`deep.md`。5 問とも本人が選んだ。どれも推奨と同じ）と、聞かずに決めたもの（C1〜C7。`defaults.md`）に従う。
**変えるのは Q7・Q8・手当てと、それが必ず変える ST23 の振る舞いだけ**（Q1）。ST23 の code review で見送った直し（R10・R23・R16・一部重なる B の前の版の本文）は入れない。

- **1 日の一覧に、P にすっぽり入る B の行を出す**（Q7・C5）。B の行は、重なりがいちばん大きい P（同じなら早い P）の「本文ごと消した」の行のすぐ下に字下げして出す。
  時間は B 自身の時間（その日の中に切る）。B が 2 つ以上なら始まりの順に並べ、B 同士が重なれば今の「消した」の行と同じ形で 1 行にまとめる。押す口は 44×44 px 以上。
  B を本文ごと消した後も、B の行は同じ P の下に「本文ごと消した」として残す（口は出さない）
- **戻しても一覧に戻らない B は戻さない**（Q2。**ST23 Q7 の答えの「B の行に『戻す』を出す」を覆す**）。
  - すっぽり入る B の行には「本文ごと消す」だけを出し、「本文ごと消した時間の中なので戻せません」と添える
  - 一部だけ重なる B の行には「戻す」を出す。ただし、戻した結果が一覧に戻らないとき（はみ出しが滞在にならない・吸収される。premises.md の探り A1・A2）は戻さずに断り、B は「消した」のまま残す
  - 戻す口（`POST /stays/restore`）も同じ B を断る（いまは 200 で B の行の印を外し、作り直しで B が隠れる）。断り方と、戻した結果が一覧に戻るかの見分け方は design で決める
  - 戻した結果が一覧に戻る B（はみ出しが滞在になる）は、いまのとおり戻せる
  - B の本文を消すのは、本人が確認を見て「本文ごと消す」を押したときだけ。本文ごと消す範囲（ST23 design D2 の 3）は広げない
- **作り直しが P と重なる滞在 L を隠したら、同じまとまりで L の本文と前の版も消す**（Q8・FR-50 ★ 2026-10-23・C1〜C4）。
  - 対象: 作り直しの前に一覧に出ていた滞在のうち、作り直しの前の時間が P と重なり（端が触れるだけは含めない）、この作り直しが隠したもの。
    作り直しが新しく作った行と、P の前から作り直しの印で隠れていた行は入れない。判定は作り直しの中で行い、時刻で比べない
  - 隠すことと本文を消すことを 1 つのまとまり（`rebuild_day` の transaction）にする。途中で落ちたら隠しもしない
  - L は `user:purged` に付け替え、削除の台帳に原因 = P の行を積む。消去の台帳に「後から」（kind = late、元の操作 = P）の操作として 1 行、滞在 1 件で載せる。
    L と前の版の時間は、その操作の範囲の行に残し、消した時間帯の窓には入れない（C7）
  - 一覧に出ている間の L は消さない（ST23 D17 のまま）
- **P の行の文言を「後から N 件も本文ごと消した」にする**（Q3）。後から届いた位置と、作り直しで隠れて本文を消した L を 1 つの数で出す。数え方（台帳の kind = late）は変えない
- **本文ごと消す確認に、一覧に出ている重なる滞在 L を添える**（Q4）。L があるときだけ「一覧に出ている重なる滞在 N 件は残ります。後で作り直しで隠れたら、その本文も消えます」と出す。
  L は確認の件数に入れない（消す範囲は変えない）
- **手当て: サーバの起動のたびに、この change の前に隠れて本文が残った L を、Q8 と同じ処理で探して消す**（Q5。**依頼の「移行か作り直しの経路」を、起動の経路に決めた**）。
  何度走っても増えない形にし、対象が 0 件なら何もしない。落ちても起動は止めず、残った件数をログに出し、次の起動で消し直す。
  P の後に隠れたかは、削除の台帳と吸収の表（`core.stay_absorbed`）の順で見分ける（時刻で比べない）。移行の SQL に同じ規則を書き写さない。
  P の前から作り直しの印で隠れていた端の滞在は入れない（`purge_scope_edge_touching_rebuild_stay_is_not_included`）

この change が変える ST23 の振る舞いは 4 つ（`docs/changes/CH08.md` の「壊してはいけないもの」）: 戻す口（Q2）・作り直しで隠した重なる滞在の本文の消去（Q8）・L の印の付け替え（C7）・1 日の一覧（Q7・Q3・Q4）。
ST23 の既存の Scenario と試験は、この 4 つが変える分を除いてそのまま通す（C6）。

**BREAKING は無い。** ST23 の利用者はまだいない（ST23 は CH08 と同じ時期に main へ入る）。外から見える変化は、`POST /stays/restore` が戻しても一覧に戻らない B を 409 で断る（確かめの作り直しが落ちれば 503）ようになることと、確認の口の応答に一覧に出ている重なる滞在の件数が足されることと、
1 日の並び（`GET /day`）の「本文ごと消した」の区間に B の行の項目が足されることだけ。既存の項目は変えない。

### Modified Capabilities

ST23 は 2026-10-30 に archive した（`openspec/changes/archive/2026-10-30-st23-record-erasure/`）。変える Requirement は正典（`openspec/specs/record-deletion/spec.md`・`openspec/specs/browsing-views/spec.md`）にあり、
spec の段は正典から要件の全文と Scenario を写して `MODIFIED` で書いた。

- **`record-deletion`**
  - MODIFIED「消したものを戻せる」—— 戻しても一覧に戻らない B を断る（Q2）
  - MODIFIED「「消した」の行から戻せる」—— すっぽり入る B の行は「本文ごと消す」だけ。一部重なる B の「戻す」は、戻した結果が一覧に戻らなければ断る（Q2・Q7）
  - MODIFIED「「消した」の行から本文ごと消せる」—— B の行から本文ごと消せる・B を本文ごと消した後の行（Q7・C5）、「後から N 件も本文ごと消した」（Q3）、確認の一文（Q4）
  - MODIFIED「本文ごと消す前に、消える件数と残るものを示す」—— 確認の口が、一覧に出ている重なる滞在の件数を消える件数の外で返す（Q4）
  - MODIFIED「本文を消した記録は戻せず、作り直しも戻さない」—— 作り直しが隠した重なる L の本文を同じまとまりで消す（Q8・C1〜C4）
  - MODIFIED「本文ごと消す操作は追記のみの台帳に 1 操作 1 行で残る」—— kind = late の操作（元の操作 = P）として L を載せ、L と前の版の時間を範囲の行に残す（C7）
  - ADDED「本文ごと消した後に作り直しで隠れたのに本文が残る重なる滞在は、サーバの起動のたびに本文を消す」—— この change の前に隠れて本文が残った L を、起動のたびに消す（Q5）
  - MODIFIED「本文ごと消す範囲は、…」—— 範囲は変えない。「一覧に出ている滞在の本文は消さない」を「この操作では」に限り、後で隠れたときは上の作り直しの規則へ送る（spec review R10）。D2 の「Q7 待ち」と D12・D17 の「Q8 待ち」は、CH08 の design（D2〜D6）が本人の決定で決着を書く（archive の ST23 design は直さない）
- **`browsing-views`**
  - MODIFIED「1 日の並びを読み出せる」—— 「本文ごと消した」の区間に、すっぽり入る B の行（識別子・時間・戻せるか）を添える（Q7）。後から本文を消した件数に L を数える（Q3）
  - MODIFIED「日付を指定するとその日の滞在が時刻順に一覧で出る」—— B の行を P の行の下に出す形（C5）
