## ADDED Requirements

### Requirement: PC の収集アプリは、記録を未送信に積む時点で自分の版を焼き込み、溜めた行の欄を落とさない

THE SYSTEM SHALL C-02 が記録を未送信に積むとき、その時点の C-02 の組み立ての印を部品の版の欄に書き込む。生存信号には書き込まない。
THE SYSTEM SHALL 未送信を送るとき、積んだときの部品の版をそのまま送る（送る時点の版で書き換えない）。
THE SYSTEM SHALL 溜めた行を読み戻したとき、部品の版の欄が無ければ、今の版を入れずに欄の無いまま送る。
THE SYSTEM SHALL 溜めた行が今の C-02 の知らない欄を持っていても、その欄を捨てずに送る。
THE SYSTEM SHALL ブラウザ履歴を読み直して送る記録には、読み直した時点の C-02 の版を書き込む（中身を作った版。外部サービス由来の更新で版が動く）。
THE SYSTEM SHALL C-02 の組み立ての印を、組み立てのたびに作り直す（版番号は `Cargo.toml`、commit は組み立てた木の HEAD、未 commit の変更があれば `.dirty`、release でない組み立てなら `.debug`）。

導出元: FR-122。扉 #32。FR-122 ★ 2026-10-25 訂正（送った時の版ではなく作った時の版）。深掘り（ST49）Q1（推奨）。design D1（仮）・D3（仮）・D13。
未送信は更新の後に送られるので、送る時点の版を付けると取り違えた版が作った記録に直した版が付く。

#### Scenario: PC の収集アプリを更新した後に送った未送信は、積んだときの版で届く

- **WHEN** 組み立ての印 `0.1.0+<commit A>` の C-02 がウィンドウの記録を未送信に積み、送る前に印 `0.1.0+<commit D>` の C-02 で置き場を開き直して送る
- **THEN** 送った要求の部品の版は `0.1.0+<commit A>`

#### Scenario: PC の版の欄を持たない未送信の行は、版の欄の無いまま送られる

- **WHEN** 版の欄を足す前の形で積まれた未送信の行を、版の欄を知る C-02 が読み戻して送る
- **THEN** 送った要求に部品の版の欄は無く、壊れた行として退避されない

#### Scenario: PC の未送信の行が知らない欄を持っていても、送るときに落ちない

- **WHEN** 今の C-02 の知らない欄 `future_field` を持つ未送信の行を読み戻して送る
- **THEN** 送った要求に `future_field` が同じ値で載っている

#### Scenario: PC の生存信号には版が書き込まれない

- **WHEN** C-02 が生存信号を未送信に積む
- **THEN** 積んだ行に部品の版の欄は無い

#### Scenario: PC の収集アプリの組み立ての印は、commit を進めた後の差分の組み立てでも新しい commit になる

- **WHEN** C-02 を組み立てた後に commit を 1 つ足し、ソースに触れずにもう一度組み立てる
- **THEN** 2 回目の組み立ての印の commit は、足した commit の 40 桁
