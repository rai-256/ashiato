## 聞かないで決めるもの（C —— 扉を開けたままにする既定）

本人には HTML の冒頭（note）で一覧として見せ、異論は補足欄に C 番号で受ける。

- **C1. 待ち受けは loopback だけを既定にし、それ以外は明示した網だけを許す**（既定は厳しい側）。
  `BIND` が loopback でなければ、`.env` に許す網（CIDR）を明示していない限り起動を拒否する。
  PERM-7 の「利用者が明示的に許可した」をこの設定で成り立たせる。家の LAN は既定で許さない
  → **spec の段で厳しい側へ変えた**（2026-09-29。spec レビュー R1。design D7（仮））: 明示した網でも平文の直の口は Q2 の答え（127.0.0.1 から動かない・網の口は暗号化だけ）と食い違うので、loopback 以外は一律に拒否する。`ALLOWED_NETS` は置かない
- **C2. 網の外に開いていないことを機械で見る。** 選んだ手段が Tailscale のときは `tailscale funnel` が有効なら落ち、
  どの手段でも待ち受けが許した網の外なら落ちる検査を置く（完了の判定「網外からは同じ URL に到達できない」を、網外の端末を用意せずに判定する）
- **C3. 網の名前・アドレスはリポジトリに書かない**（`tools/check-private.sh` の既存の規則。許す網も `.env` にだけ書く）。
  既存の規則は `*.ts.net` と IP の形しか見ないので、pre-commit では手元の機械の短い名前（MagicDNS）もその場で読んで禁止語に加える（**R12**）
- **C4. 応答に `Cache-Control: no-store` を付け、端末のブラウザに記録を残さない。** オフラインで見る仕組みは作らない（**R7**。当初の Q3。厳しい側で、費用は応答ヘッダ 1 つ）
- **C5. 誰がいつ読んだかを追記のみの台帳に残す**（「台帳は追記のみ」「列を持つ」）。時刻・経路（loopback / 網）・資格情報の種類（画面のログイン / 収集の合言葉 / 読み出し用）・route だけを残し、
  中身と識別子の文字列は残さない（製造準備 A-2 と揃える）。記録しなかった期間の読み出しは後から足せない（**R9**。loss: uncaptured —— 持つ側は何も失わず費用が小さいので問いにしない）
- **C6. 画面は外部の資源を読まない。** 画面の応答に `Content-Security-Policy: default-src 'self'` を付け、e2e で外部への要求が 0 件であることを測る
  （地図のタイルを外から読むと表示範囲の座標が網の外へ出る。いまは 0 件なので失われるものは無い）（**R10**）
- **C7. spec には事業者の名前を書かない**（PERM-7 に揃える。「利用者が明示的に許可した私設網」で書き、Tailscale は design の既定の手段に置く）。
  §1.4・§5 の技術的制約・ST28 の題と完了の判定の文言は、`record` で PERM-7 に揃える（**R11**）
