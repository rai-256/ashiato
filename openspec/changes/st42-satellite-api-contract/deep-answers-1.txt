=== ST42 の深掘り の回答 ===
Q1 [版の示し方] -> 道に版を入れる（/satellite/v1/…）
Q2 [壊す変更の見分け方] -> 自前の台本で、決めた規則を見る
Q3 [比べる相手] -> 版ごとの写し（main にあるもの）と比べる
Q4 [確かめる口が返すもの] -> 受ける版の一覧を返す（例: 1.2 と 2.0）
Q6 [前の版を並べる期間] -> 新しい版を最初に配った日（印）から数える
Q7 [同じ版の中の追加] -> 小さい番号を上げる（1.0 → 1.1）
Q8 [外した版・無い版を呼ばれたとき] -> いま決める: 断り＋版の一覧、外す前は見出しで予告
QA [仕様への合意] -> 合意する
