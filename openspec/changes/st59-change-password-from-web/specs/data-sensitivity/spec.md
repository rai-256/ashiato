## MODIFIED Requirements

### Requirement: 画面のログインは期限で切れず、画面の合言葉を変えると全部が無効になる

THE SYSTEM SHALL 既定では、画面のログインの印を時間の経過で無効にしない（ログアウトするまで使える）。
THE SYSTEM SHALL ログインの印を、ブラウザを閉じても残る寿命で覚えさせ、印で認めた応答のたびにその寿命を延ばす。
THE SYSTEM SHALL 画面の合言葉が変わった後の起動で、変わる前に発行したすべてのログインの印を無効にする。
WHEN 本人が画面の設定から画面の合言葉を変える（「画面は、ログインして今の画面の合言葉を入れ直したときだけ、画面の合言葉を変える」） THE SYSTEM SHALL 起動し直すのを待たずに、変えた時点で、変える前に発行したすべてのログインの印を無効にする（変えた画面には新しい合言葉に結び付いた印を渡す）。
THE SYSTEM SHALL ログインの印の鍵（「画面のログインの印の鍵はサーバだけが持つ」）が変わった後の起動で、変わる前に発行したすべてのログインの印を無効にする。
THE SYSTEM SHALL API の合言葉が変わっても、ログインの印を無効にしない。
WHERE 利用者が設定でログインの期限を与えている THE SYSTEM SHALL 発行からその期間を過ぎた印を無効にする。

導出元: PERM-10。深掘り Q6（推奨の 30 日を本人が覆した）。
端末を落としたときに、その端末のログインを締め出す手段は、期限の代わりに画面の合言葉を変えることだけになる。
ブラウザは覚える寿命に上限を持つ（design の D18）ので、長く開かなかった端末ではもう 1 度ログインになることがある。
★ ST44（深掘りの AI の既定・design D7）: 前は API の合言葉を変えてもログインが全部切れた（印の鍵が API の合言葉だった）。鍵をサーバだけが持つ値に替えたので、
収集アプリの合言葉を替えても画面のログインは続く。ログインを締め出す手段は、画面の合言葉か印の鍵を変えること。
★ ST59（FR-133。深掘り Q1 の推奨・review/deep.md R2・C2）: 画面の設定から合言葉を変えられるようにした。サーバは新しい照らす値を設定のファイルに書いてから止まらずに差し替えるので、
拾われた携帯のログインは、起動し直すのを待たずに次の操作で断られる。設定のファイルを手で書き換えた・インストーラの `password` で決め直したときは、今どおり次の起動で無効になる。

### Requirement: 誰がいつ読んだかを、追記のみの読み出しの記録に残す

THE SYSTEM SHALL 記録の読み出しと、ログイン（成功・失敗・一時的な断り）・ログアウトと、画面の合言葉と収集アプリの値を変える求め（変えたもの・断ったもの）と、資格情報の無いか一致しない求めと、衛星の資格情報で断った求めと、API の合言葉で許可の一覧の外の口に届いて断った求めを、1 件ごとに読み出しの記録に 1 行残す。
THE SYSTEM SHALL 資格情報が認められた取り込み（記録・生存信号・破棄の報告を送る求め）を、読み出しの記録に残さない。衛星の資格情報で取り込みの口に届いた求めは、断ったものとして残す。
THE SYSTEM SHALL 読み出しの記録の行に、時刻・経路（直接か、網の手段を経て届いたか）・資格情報の種類（画面のログイン / API の合言葉 / 衛星 / 無し）・口の名前・結果だけを持たせ、
資格情報の種類が衛星の行にはさらに、どの衛星か・どの 1 本の資格情報かを本体の中の番号で持たせる。
記録の中身・求めの引数・合言葉・ログインの印・衛星の資格情報の値・衛星の識別子の文字列・記録と利用者の識別子の文字列を持たせない。
THE SYSTEM SHALL 衛星の資格情報で断った求めと、API の合言葉で許可の一覧の外の口に届いて断った求めの行の結果を、実際に返した応答（403）のとおりに書く。
WHEN 読み出しの記録に行を書けない THE SYSTEM SHALL その読み出しの求めに記録を返さず、500 で断る。
THE SYSTEM SHALL 読み出しの記録を追記のみとし、書き換え・行の削除・表の切り詰めのいずれも拒む。
THE SYSTEM SHALL 読み出しの記録の行を、記録の読み出しに出さない。
THE SYSTEM SHALL 画面の合言葉と収集アプリの値を変える求めの行の結果を、変えたものは `ok`、ログインの印の無いものは `unauthorized`、回数の制限で断ったものは `login_throttled`、それ以外の断りは `forbidden` とし、状態を実際に返した応答のとおりに書く。変えたものの行は値を書き戻す前に書き、書けなければ何も変えずに 500 で断る。行を書いた後に値を書き戻せなかったときは、結果が `forbidden`・状態が 500 の行を足す（打ち消しの行）。

導出元: PERM-10 / PERM-7 / PERM-14。深掘り C5（loss: uncaptured —— 残さなかった期間の読み出しは後から足せない。書けないときに返すと、その読み出しが黙って抜ける）。
製造準備 A-2（中身をログに残さない）。
経路の「網の手段を経て届いた」は中継が付ける印からの判定で、同じ PC のプロセスが偽れる。手がかりとして残す。
取り込みを残さないのは「誰がいつ読んだか」を残すためで、収集は数分ごとに来る。

発行できる（PERM-14）ので、漏れた 1 本を後から特定する手がかりは、求めごとの行にその 1 本の番号があるときだけ残る（最後に使われた時刻は上書きされる）。
「識別子の文字列を持たせない」が禁じるのは記録と利用者の識別子（PERM-13 ★ C6。衛星が何を読んだかは別の台帳（ST45）に残す）で、衛星と資格情報の番号は呼び出し元を指すもの。
衛星の求めは承認（ST38）までどの口でも断るので、ST29 の衛星の行の結果はどれも 403 になる。
★ ST44（深掘りの AI の既定）: API の合言葉で許可の一覧の外の口に届いた求めを、資格情報の種類が API の合言葉・結果が 403 の行で残す。落とした電話の値で読もうとした跡が残る。
許可の一覧の中の取り込み（記録・生存信号・破棄の報告）は今どおり残さない。
★ ST59（review/deep.md R1・C1。D9（仮））: 画面の合言葉と収集アプリの値を変える求めを、口ごとに分けて残す。拾った人が合言葉を試した・変えた跡は、残さなかった期間の分を後から足せない。

## ADDED Requirements

### Requirement: 画面は、ログインして今の画面の合言葉を入れ直したときだけ、画面の合言葉を変える

THE SYSTEM SHALL 画面の設定に「画面の合言葉を変える」の節を置き、本人が今の合言葉・新しい合言葉・新しい合言葉（もう一度）を入れて「変える」を押すと、画面の合言葉を新しい合言葉に変える。
THE SYSTEM SHALL 変える口（`POST /web-password`）を、有効な画面のログインの印を持ち、かつ本文の今の合言葉が画面の合言葉と一致する求めにだけ答えさせる。今の合言葉が違えば 403（本文 `{"error": "wrong_password"}`）で断って何も変えず、ログインは保つ。ログインの印が無ければ 401、API の合言葉か衛星の資格情報なら 403 で断る。
THE SYSTEM SHALL この口の今の合言葉の照合に、ログインの口と同じ失敗の遅れと回数の制限を当て、失敗の数えを、ログインの口・収集アプリの設定の文字列を出す口・収集アプリの値を変える口と共有する（どの口で失敗しても同じ窓で数え、超えたら正しい合言葉でも 429 で断る）。合言葉や収集アプリの値を変えても、失敗の数えを数え直さない。
THE SYSTEM SHALL 本文が JSON と名乗らない求めを 415 で断る（よそのサイトの単純な送信を受けない）。
THE SYSTEM SHALL 断る理由を、ログインの印 → 呼び出し元の種類 → 本文の形 → 開発の形か → 回数の制限 → 今の合言葉 → 新しい合言葉の検査、の順に見て、最初に当たったもので断る（今の合言葉が違う求めには、新しい合言葉の検査の結果を返さない。開発の形では今の合言葉を照らさない）。
IF 新しい合言葉が、16 文字より短い・`change-me` で始まる・収集アプリの値と同じ・ログインの印の鍵と同じ・もう一度の入力と一致しない、のどれかに当たる THEN THE SYSTEM SHALL 400（本文 `{"error": "<理由>"}`。理由は順に `too_short`・`placeholder`・`same_as_api_token`・`same_as_session_key`・`mismatch`）で断り、何も変えない。
WHERE サーバが設定のファイルを指さずに起動している（`.env` の元の合言葉で起こした開発の形） THE SYSTEM SHALL この口への求めを 409（本文 `{"error": "not_changeable"}`）で断って何も変えず、画面は「この形のサーバでは画面から変えられません。.env を書き換えて起動し直してください」と出す。
THE SYSTEM SHALL 新しい合言葉の照らす値を設定のファイルに書き終えてから、サーバの照らす値をその値に差し替える。書けなければ 500（本文 `{"error": "not_saved"}`）で断り、今の合言葉のまま動き続け、画面は「保存できませんでした。合言葉は変わっていません」と出す。
THE SYSTEM SHALL 設定のファイルを書き直すとき、画面の合言葉の照らす値の 1 つの鍵だけを置き換え、ほかの鍵と値を変えず、書きかけの中身を設定のファイルの名前で残さない。
THE SYSTEM SHALL 差し替えたら、変えた求めの応答で新しい合言葉に結び付いたログインの印を渡し（変えた画面はログインしたまま）、それより前に発行したすべてのログインの印をその場で無効にする。その印を用意できなければ、設定のファイルを書く前に 500 で断り、何も変えない。
THE SYSTEM SHALL 差し替えた後に返す応答で、無効になった印の寿命を出し直さない（差し替えの前に始まった求めの応答が、変えた画面の新しい印を古い印で上書きしない）。
THE SYSTEM SHALL 変える処理と、ほかの口の合言葉の照合を 1 つずつ通し、変える前の合言葉で照合が通ったログインに、変えた後も使える印を渡さない。
THE SYSTEM SHALL 変えた後に起動し直しても、新しい合言葉でログインでき、前の合言葉ではできないようにする。
THE SYSTEM SHALL 画面で変えた後も、インストーラの `password` の口で画面の合言葉を決め直せるようにする。
THE SYSTEM SHALL 入れた合言葉（今のもの・新しいもの）と照らす値を、読み出しの記録・ログ・応答の見出しと本文に出さない。
THE SYSTEM SHALL 設定の「画面の合言葉を変える」と「収集アプリの値を変える」の 2 つの節の近くに、「携帯を落としたときは両方を変える」と出す。

導出元: FR-133・PERM-10。深掘り Q1・Q2・Q3（推奨）。review/deep.md R2・R3・R4・R6・R11・C2・C3・C4・C5。D1〜D5・D8（仮）。
合言葉を入れ直させるのは、ログインしたままの携帯を拾った人に合言葉を変えさせないため（FR-133 の ★ 2026-11-03）。拾った人が合言葉を知らなければ、本人の合言葉は変わらない。
新しい合言葉の検査は、インストーラの決め直し（`distribution` の「画面の合言葉を忘れたら、インストーラで管理者として決め直せる」）と同じ 5 つ。起動の検査に落ちる値を書くと、次の起動でサーバが起きなくなる（review/deep.md R6）。
設定のファイルを指さない開発の形には、書き戻す置き場が無い（`.env` は開発者が手で書く）。開発の形で差し替えると、起動し直したときに黙って `.env` の古い値に戻る（Q3）。

#### Scenario: 今の合言葉を入れ直すと画面の合言葉が変わり、前の合言葉ではログインできない

#### Scenario: 設定のファイルに書けないと、画面は合言葉が変わっていないと出す

- **THEN** 「保存できませんでした。合言葉は変わっていません」と出て、ログインは保たれて設定の画面に留まり、前の合言葉でログインできる

#### Scenario: 今の合言葉が違えば、新しい合言葉が検査に当たっても今の合言葉の違いで断る

### Requirement: 画面は、ログインして今の画面の合言葉を入れ直したときだけ、収集アプリの値を変え、新しい設定の文字列を出す

THE SYSTEM SHALL 画面の設定に「収集アプリの値を変える」の節を置き、本人が今の合言葉を入れて「変える」を押すと、収集アプリの値（携帯と PC で共有する 1 本の値）を新しい値に変え、新しい値の設定の文字列（「収集アプリの設定」と同じ形・同じ送り先）と、それをコピーするボタンと、案内「全部の収集アプリ（携帯と PC）にこの文字列を貼り直してください。携帯に入れる文字列は、携帯から開いた画面で『収集アプリの設定』から出してください」を出す（画面を `127.0.0.1` で開いていると、その文字列の送り先を携帯は断るため）。
THE SYSTEM SHALL 新しい値をサーバが OS の暗号の乱数で作り、本人に入れさせない。新しい値を、ログインの印の鍵と同じ値・画面の合言葉に当たる値にしない。
THE SYSTEM SHALL 変える口（`POST /collector-token`）を、有効な画面のログインの印を持ち、かつ本文の今の合言葉が画面の合言葉と一致する求めにだけ答えさせ、答えに新しい値を返す。今の合言葉が違えば 403（本文 `{"error": "wrong_password"}`）で断って何も変えず、ログインは保つ。ログインの印が無ければ 401、API の合言葉か衛星の資格情報なら 403 で断る。
THE SYSTEM SHALL この口の今の合言葉の照合に、画面の合言葉を変える口と同じ失敗の遅れと回数の制限を当て、失敗の数えを共有する。
WHERE サーバが設定のファイルを指さずに起動している THE SYSTEM SHALL この口への求めを 409（本文 `{"error": "not_changeable"}`）で断って何も変えない。
THE SYSTEM SHALL 新しい値を設定のファイルに書き終えてから、サーバの収集アプリの値をその値に差し替える。書けなければ 500（本文 `{"error": "not_saved"}`）で断り、前の値のまま動き続ける。
THE SYSTEM SHALL 設定のファイルを書き直すとき、収集アプリの値の 1 つの鍵だけを置き換え、ほかの鍵と値を変えず、書きかけの中身を設定のファイルの名前で残さない。
THE SYSTEM SHALL 差し替えた時点から、前の値を付けた求めを資格情報の一致しない求めとして 401 で断り、新しい値を付けた求めを収集アプリの資格情報として通す（前の値を受ける猶予を置かない）。画面のログインは無効にしない。
THE SYSTEM SHALL 変えた後に起動し直しても、新しい値で動くようにする。
THE SYSTEM SHALL 新しい値と前の値を、読み出しの記録・ログ・応答の見出しに出さない（値は応答の本文で、変えた本人の画面にだけ返す）。
THE SYSTEM SHALL 画面を開き直す・別の画面へ移ると、出した新しい値の設定の文字列を画面から消す（もう一度出すには「収集アプリの設定」で合言葉を入れ直す）。
