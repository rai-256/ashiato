# ST53 の前提（外の形式・振る舞い）

問いを立てる前に確かめたもの。確かさは story-upstream の 1〜5（1 言っただけ / 2 出所を示した / 3 辿った / 4 走らせた / 5 実物で再現した）。
失われるもの（`loss`）のある問い（Q1〜Q4）が依る前提は、Q1 が P1、Q2 が P1・P2・P10、Q3 が P7・P8・P11・P12、Q4 が P13。P1・P2・P7・P10・P12（資格情報が admin）・P13 は確かさ 4 以上。
P8（承認の仕組みが公開リポジトリで使える）・P11（印の push の workflow は印の commit の定義）・P12 の後半（権限を絞った token）は公式文書の 2 で、推奨の側の守りの前提（外れても、失う側の選択は変わらない —— P11 が外れれば経路そのものが無く、P8・P12 後半が外れれば推奨が成り立たず別の選択肢へ移るだけ）。tasks で、使い捨ての Environment と使い捨ての値で走らせて 4 に上げる。
P9 の文の型は知識（1）で、何の決定も載せない（Q1 は英文の案そのものを本人に見せて決める。型は書き方の参考に留める。review/deep.md R3）。
