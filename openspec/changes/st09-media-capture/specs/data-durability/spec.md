## ADDED Requirements

### Requirement: 写真と画像と動画のソースと、ST09 が足す欄と表は書き出しの分類に載る

THE SYSTEM SHALL `c01-photo` / `c01-screenshot` / `c01-image` / `c01-video` を、書き出しの「緯度経度を持つ」ソースとして扱う（撮影位置を持ちうる）。
THE SYSTEM SHALL `c01-photo` / `c01-screenshot` / `c01-image` の記録の時刻の幅を「時刻 1 点」（撮影の時刻だけ）として読む。
THE SYSTEM SHALL `c01-video` の記録の時刻の幅を、記録が長さを持てば撮影の時刻からその長さの後まで、持たなければ撮影の時刻だけとして読む。
THE SYSTEM SHALL 生存信号の接続の有無の欄を、生存信号のファイルの列として書き出しに出す。
THE SYSTEM SHALL 原本の受け取りの台帳・原本の欠けの報告・文字抽出の結果の表を、書き出しに入れず、説明書の「入らないもの」に名前を挙げる。
THE SYSTEM SHALL 写真と画像の原本（D-02）を、今までどおり書き出しに入れない。

導出元: NFR-16。ST09 の深掘り C15 / Q16、独立レビュー R14。正典の「書き出しは本人が消した場面を出さない」「書き出しは台帳・導出・内部の表と、消したことの痕跡を入れない」の分類の規則に、ST09 が足すものを載せる。
分類の無い表・列・ソースがあると書き出しは始まらない（正典）ので、足す Story が載せる。
原本の受け取りの台帳と原本の欠けは、D-02 にあるものとの突き合わせ（ST10）の材料で、書き出しが持つ記録・稼働の元データの外に置く（D-02 も書き出しに入らない）。
文字抽出の結果は中身が空のまま（FR-32）で、入れるかどうかは結果を書き始める Story（ST35）が決め直す（design D18）。
接続の有無を出すのは、取れる状態か・妨げと同じく稼働の元データで、取得の回数のような「ここで消した」を読ませる値ではないため。

#### Scenario: 消した滞在の時間に撮った撮影位置つきのスクリーンショットと画像は書き出しに出ない

- **WHEN** 01:00〜02:00 の滞在を消した後、01:30 に撮影され撮影位置を持つスクリーンショットとカメラ以外の画像の記録がある状態で書き出す
- **THEN** 記録のファイルにどちらの記録も出ない

#### Scenario: 消した時間の前に撮り始め、長さで重なる動画は書き出しに出ない

- **WHEN** 01:00〜02:00 の滞在を消した後、00:55 に撮り始めた長さ 10 分の撮影位置つきの動画の記録がある状態で書き出す
- **THEN** 記録のファイルにその動画の記録は出ない

#### Scenario: 消した時間の後に撮った写真は書き出しに出る

- **WHEN** 01:00〜02:00 の滞在を消した後、02:01 に撮影され撮影位置を持つ写真の記録がある状態で書き出す
- **THEN** 記録のファイルにその写真の記録が出る

#### Scenario: 生存信号の接続の有無は書き出しに出る

- **WHEN** 接続が無かったことを持つ写真の生存信号を受けてから書き出す
- **THEN** 生存信号のファイルのその行は接続の有無の列を持ち、接続が無かったことを示す

#### Scenario: 原本の台帳と原本の欠けと文字抽出の表は書き出しに入らない

- **WHEN** 原本の受け取りと原本の欠けが 1 件ずつある状態で書き出す
- **THEN** zip の中に、原本の受け取り・原本の欠け・文字抽出の結果のファイルは無く、D-02 の原本のファイルも無い

#### Scenario: 説明書の入らないものに原本の台帳と欠けと文字抽出が挙がる

- **WHEN** 書き出し、zip の中の説明書を読む
- **THEN** 「入らないもの」に、原本の受け取り・原本の欠け・文字抽出の結果と、写真と画像の原本（D-02）が挙がっている

#### Scenario: ST09 が足したソースと表と列はすべて分類されている

- **WHEN** すべての移行を当てた DB で、登録簿のソースと記録の schema の表と書き出しに入れる表の列を一覧にして、書き出しの分類と突き合わせる
- **THEN** `c01-screenshot` / `c01-image` / `c01-video`、原本の受け取りと欠けと文字抽出の表、生存信号の接続の有無の列のどれにも分類があり、分類の無いものは 0 個である
