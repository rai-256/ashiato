=== ST09 の深掘り の回答 ===
Q1 [いまの端末にある写真と動画の量] -> 補足欄に書いた
  補足: 多分合わせて29gbですが、細かくわかりません。
Q2 [端末から写真を消すか] -> 「空き容量を増やす」などでまとめて端末から消すことがある
Q3 [導入した時点で端末にある過去の写真・動画] -> 端末にあるものは全部取り込む（過去のものも、見ていなかった間のものも）
Q4 [原本を送るまで、端末のどこに置くか] -> 写しを作らず、送るときに端末の写真を読む
Q5 [「写真」に何を含めるか] -> 端末に保存される画像の全部（メタも原本も）
Q6 [動画で送るもの] -> メタだけ（要件どおり）
Q7 [取り込んだ後で写真が編集・上書きされたとき] -> 変わった後の版も取る（メタも原本も。前の版も残す）
Q8 [取り込んだ写真が端末から消えたとき] -> 消えた事実を記録する
Q9 [原本をどの通信で送るか] -> 新しく撮ったものはどの通信でも送る。初回の過去ぶんは Wi-Fi のときだけ
Q10 [圏外の日の、写真の「取れる状態だったか」] -> 接続が無いだけなら「取れる状態」と数える（写真と動画）
Q11 [新しい写真を見つける頻度] -> 保存されたら知らせを受けてすぐ。念のため 6 時間ごとにも見直す
Q12 [自宅 PC の原本のフォルダの並び] -> 撮影の年/月のフォルダに、撮影日時と元のファイル名で並べる
Q13 [過去の写真で「収集を始めた日」を遡らせるか] -> 写真は「見始めた日」を収集を始めた日にする（集計と同じ例外）
Q14 [写真の「出来事の時刻」に何を採るか（撮影時刻が無い・狂っているとき）] -> 撮影時刻。無い・狂っているときは端末に保存された時刻（どちらを採ったかを印にする）
Q15 [写真の位置の権限が無いとき] -> 権限が戻るまで、写真も動画も取らずに待つ（端末で知らせる）
Q16 [滞在を消したとき、その時間の写真・動画] -> 含めない。写真は写真を消したときだけ消える
