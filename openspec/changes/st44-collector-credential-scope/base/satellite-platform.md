### Requirement: 衛星の登録と資格情報の操作は、画面のログインでだけできる

THE SYSTEM SHALL 衛星の一覧の読み出し・衛星の登録・資格情報の発行・資格情報の取り消し・衛星を外す、を画面のログインの印を持つ求めにだけ許す。
THE SYSTEM SHALL これらの口に、API の合言葉か衛星の資格情報を付けた求めを 403 で、資格情報の無い求めを 401 で断る。

導出元: PERM-10 / PERM-14。深掘り C13。
資格情報を発行する口は、外へ出す向きの操作（衛星に資格情報を渡す）の入口なので、携帯に埋め込んだ合言葉（API の合言葉）にも衛星自身にも許さない。
API の合言葉で通るいまある口の範囲は変えない（ST44）。

#### Scenario: API の合言葉では衛星を登録できない

- **WHEN** API の合言葉を付けて、衛星の一覧の読み出し・衛星の登録・資格情報の発行・資格情報の取り消し・衛星を外す、をそれぞれ求める
- **THEN** どの求めも 403 で断られ、衛星の一覧と資格情報は変わらない

#### Scenario: 資格情報が無いと衛星の一覧も読めない

- **WHEN** 資格情報を付けずに衛星の一覧の読み出しと衛星の登録を求める
- **THEN** どちらの求めも 401 で断られる
