### A-5. 骨に残っている未決のうち、期限が「製造開始前」のもの

**扉の正典は要件 §5 に一本化している。** 本フローは骨（skeleton）の工程を持たず、
`reference/skeleton/doors.md` は旧プロジェクトの読み取り専用資料なので拾わない

#### 閉じた扉

- **#24 バックアップ暗号鍵の保管方式** — 期限は要件上「初回バックアップの実行前」（ST31 / layer 5）
  だったが、A-3 が「失えば全データが消えるものは入れ始める前に決める」と要求しているので**前倒しで閉じた**。
  決定内容は A-3 の表のとおり。

#### 期限を引き直した扉（理由つき）

- **#25 画面キャプチャの保持期間と文字抽出エンジン** — 期限は「画面キャプチャの収集を開始する前」の
  まま**据え置く**。画面キャプチャは Could（FR-74 / ST35 / layer 4）で、製造準備の時点では
  実装対象ですらない。**いま決めると、実測なしの値が正典になる**。
  ただし版を記録する列（FR-32）は day one で持つので、後から選り分ける手段は失わない。

#### 期限が「製造開始前」の扉

**該当なし。** 未決の扉は #24 と #25 の 2 つだけで、#24 は前倒しで閉じ、#25 は期限が後ろにある。
