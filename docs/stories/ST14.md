# ST14 — 収集が途切れたら気づける

## 価値

本人として、収集が止まったら教えてほしい。なぜなら、1 年間途切れないことが成功条件 1 で、止まったことに半年後に気づいても手遅れだから。

## 満たす要件（requirements.md から逐語）

> - **FR-35**: IF あるソースの最後の記録からの経過時間が、そのソースに登録された想定間隔の
>   3 倍を超える THEN THE SYSTEM SHALL 利用者に通知する。
>   想定間隔の初期値は 位置 = 6 時間 / アプリ利用 = 6 時間 / ブラウザ履歴 = 24 時間 /
>   Takeout 系 = 60 日。
