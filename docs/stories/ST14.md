# ST14 — 収集が途切れたら気づける

## 価値

本人として、収集が止まったら教えてほしい。なぜなら、1 年間途切れないことが成功条件 1 で、止まったことに半年後に気づいても手遅れだから。

## 満たす要件（requirements.md から逐語）

> - **FR-35**: IF あるソースの**最後の記録または最後の生存信号（FR-78）**からの経過時間が、
>   そのソースに登録された想定間隔の 3 倍を超える THEN THE SYSTEM SHALL 利用者に通知する。
>   **退役したソース（FR-54 / FR-61）は通知しない。**
>   **本人が書いた記録（FR-25）のソースは対象にしない**（主観 FR-36・個人属性 FR-44・場所の登録 など）。
>   **生存信号は「取得できる状態」（FR-78）のものだけを「生きている」と数える。**
>   **観測ではない記録（取りこぼしの期間を主張する記録・時計の測定・離席・止まっていた期間・除外の印）は「最後の記録」に数えない。**

## 壊してはいけないもの

- ST02 の稼働記録

## 完了の判定

- 位置の収集を 18 時間以上止めると通知が来る
- Takeout 系のソースは、正常な 2 か月周期では通知が来ない
- 退役したソースは、最後の記録からどれだけ経っても通知しない
- 書庫のソースは、最後の書庫から 75 日を過ぎると通知が来る（Chrome の履歴が取得元から消える 90 日より前）
- 生存信号が「取得できない状態」のまま想定間隔の 3 倍を過ぎると通知が来る
