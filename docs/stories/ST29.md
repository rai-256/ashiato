# ST29 — 衛星を登録すると、衛星ごとの資格情報が発行される（まだ何も読み書きできない）

## 価値

本人として、読書ログや家計簿のような衛星を後から気軽につなぎたい。なぜなら、思いつきをその都度本体を直して足すのは続かず、どの衛星が何を書いたか・読んだかは、衛星ごとの資格情報が無いと分けられないから。

## 壊してはいけないもの

- ST28 の画面のログインと API の合言葉
- ST01 の API 契約（資格情報を求めない口は生存確認・ログイン・ログアウトだけ）

## 完了の判定

- 衛星を登録すると、その衛星の名前の付いた資格情報が発行される。「外部 AI」「ローカル AI」の 2 つの衛星は最初から登録されている
- 衛星の資格情報では、まだどの口も記録を返さず受け取らない（読むのは承認の後、書くのは書き手の列の後）。登録を外すとその資格情報は無効になる
- 衛星は別プロセスから HTTP でだけ届き、本体のプロセスにコードが読み込まれない（AGPL-3.0 の境界）
