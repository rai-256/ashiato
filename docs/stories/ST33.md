# ST33 — 全記録を外部の道具で読める形に書き出す

## 価値

本人として、いつでもデータを持ち出せる状態でいたい。なぜなら、データ所有・可搬性がこのシステムの第一の優先順位だから。

## 満たす要件（requirements.md から逐語）

> - **NFR-16**: D-01 の全記録（**本人が消した場面を除く**）は、外部の道具で読める形式に書き出せる。
>   **除くのは、削除の印の付いた記録と、本人が消した滞在の時間に入る緯度経度を持つ行（ソースを問わず。前の版を含む）。**
>   書き出したファイルは本システムが自宅 PC の決まったフォルダにだけ置き、画面から端末へは渡さない。
>   ★ 2026-09-29 訂正。ST33 の深掘り Q1 / Q5 の決定。削除の印を付けるのは滞在と位置のソースだけで、
>   書庫の位置・写真の位置・生きている滞在の前の版が同じ場面の緯度経度を持つ。印だけを見て書き出すと、
>   FR-50（ST22 の Q1）で消した場面の緯度経度が外へ出て戻らない。
