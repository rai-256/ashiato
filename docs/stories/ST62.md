# ST62 — 正式版とベータ版の札を、操作 1 つで番号へ動かして出す

## 価値

本人として、ベータ版で試した番号を、組み直さずにそのまま正式版にしたい。札を動かす操作は 1 つで済ませたい。なぜなら、番号の中にチャンネルを書き込む形では、試した物と出す物が別の組み立てになり、版を出す操作も重かったから（依頼 #352）。

## 満たす要件（requirements.md から逐語）

> - **FR-105**: THE SYSTEM SHALL 正式版（本番）・ベータ版・開発版の 3 つのチャンネルを、版番号を指す札で分けて配る。

## 壊してはいけないもの

- 印 `v*` の push に付いていた守り —— 本人の承認・正式な鍵を開く範囲・組み立ての前の脆弱性の検査・ルールセット（FR-135 の ★ 2026-11-21）

- 配布物に同梱する許諾と、対応するソースの場所（`SOURCE.txt`。FR-127）
- 携帯の APK の正式な鍵の署名（扉 34）

## 完了の判定

- 本人が操作 1 つで正式版（またはベータ版）の札を番号へ動かすと、その番号の組み立てが組み直されずに、その札の配布物として配布元に並ぶ（中身の指紋がベータ版で試した物と同じ）
- 札を後で別の番号へ動かしても、一度札を付けた番号の移行を変える PR と、その番号の送信契約の版を断る変更は CI が落とす
- 札を動かす操作は本人の承認が無いと進まず、そのときの依存の脆弱性の検査が通らなければ配布元に置かない
