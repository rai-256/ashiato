# ST23 — 本文を本当に消せる

## 価値

本人として、手元に置いておきたくないものは本文ごと消したい。なぜなら、削除する理由は大抵「記録を残したくない」で、印を付けるだけでは本文が DB に残り続けるから。

## 満たす要件（requirements.md から逐語）

> - **FR-51**: WHEN 利用者が本文の物理削除を指示する THE SYSTEM SHALL
>   対象の本文を消去し、削除した事実・時刻・件数・範囲を**台帳に**残す。
>   **消去は履歴に残した前の版にも及ぶ。** 台帳の行が同じトランザクションに無い消去は
>   DB が拒み、**台帳そのものは追記のみ**（書き換えも行の削除も表の切り詰めも拒む）。
>   ★ 2026-09-11 訂正。ST03 の深掘り Q12 / Q17 / Q23 の決定。
>   原文を残すと決めた以上、**消去が唯一の正当な開口部**になる。台帳で縛らないと、
> …（続きは requirements.md）

> - **FR-52**: WHEN 利用者が本文の物理削除を指示する THE SYSTEM SHALL
>   実行前に対象件数を提示して確認を求める。
