# ST23 — 本文を本当に消せる

## 価値

本人として、手元に置いておきたくないものは本文ごと消したい。なぜなら、削除する理由は大抵「記録を残したくない」で、印を付けるだけでは本文が DB に残り続けるから。

## 満たす要件（requirements.md から逐語）

> - **FR-51**: WHEN 利用者が本文の物理削除を指示する THE SYSTEM SHALL
>   対象の本文を消去し、削除した事実・時刻・件数・範囲を残す。

> - **FR-52**: WHEN 利用者が本文の物理削除を指示する THE SYSTEM SHALL
>   実行前に対象件数を提示して確認を求める。

## 触れる扉（requirements.md §5 から逐語）

（satisfies する要件は、扉リストのどの項の関与要件にも現れない）

## 効いてくる未決（requirements.md から逐語）

（要件本文に [NEEDS CLARIFICATION] マーカーは無い。旧形式の未決は OPEN 表 / DDR 台帳側にある — 移行の課題）

## 壊してはいけないもの

- ST22 の論理削除
- ST03 の重複判定（消したものが再流入しないこと）

## 完了の判定

- 物理削除を指示すると、実行前に対象件数が出て確認を求められる
- 実行後、本文が DB から消え、削除した事実・時刻・件数・範囲が残っている
