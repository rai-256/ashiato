# ST59 — 合言葉を画面から変えられる

## 価値

本人として、画面の合言葉と収集アプリの共有の値を、ログインした後の画面の設定から変えたい。なぜなら、サーバをサービスにしたので設定は本人が手で書き換えられる置き場に無く、携帯を落としたときに締め出す手段が無いから（docs/audit/2026-11-03-native-postgres-consistency.md の C9）。

## 満たす要件（requirements.md から逐語）

> - **FR-133**: THE SYSTEM SHALL 画面の合言葉と、収集アプリが使う共有の値（FR-128）を、V-01 にログインした後の設定から変えられるようにする。
>   ★ 2026-11-03 追加。整合の確認（`docs/audit/2026-11-03-native-postgres-consistency.md`）の C9 と `docs/briefs/req-native-postgres-r3.html` の Q3（本人が選んだ。推奨はサーバの管理用のコマンドだった）。
>   設定はサービスのアカウントだけが書ける置き場に入る（FR-109）ので、いまの `.env` を書き換える手順（`docs/network.md` §4）は配る形では使えない。FR-111 はインストールの最後に決める口だけだった。
>   問いに書いた弱み: 携帯から画面に入れると、携帯を落としたときにその携帯からも変えられる。**変えるときは今の画面の合言葉を入れ直させる**（AI の推奨。ログインしたままの携帯を拾われても、合言葉を知らなければ変えられない）

## 触れる扉（requirements.md §5 から逐語）

（satisfies する要件は、扉リストのどの項の関与要件にも現れない）

## 壊してはいけないもの

- 画面のログインとセッション（ST28・ST44）
- 収集アプリの共有の値で送ることだけができる守り（ST44）と、設定し直しを促す動き（ST56）

## 完了の判定

- ログインした後の設定で、今の画面の合言葉を入れ直すと、画面の合言葉を変えられ、古い合言葉ではログインできなくなる
- 収集アプリの共有の値を変えると、古い値の収集アプリは送れなくなり、記録を捨てずに設定し直しを促される
- ログインしたままでも、今の画面の合言葉を知らなければ変えられない
