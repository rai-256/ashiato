# 貢献者ライセンス同意（CLA）

このプロジェクトへコードを提供するときは、次に同意していただきます。
**Pull Request の本文に `I agree to the CLA in CONTRIBUTING.md.` と 1 行書くことで同意とみなします。**

## 1. 著作権はあなたに残ります

提供分の著作権を譲渡していただくものではありません。

## 2. こちらに与えていただく許諾

提供分について、プロジェクトの管理者に対し、**取り消せない、世界中で有効な、無償の、
再許諾できる許諾**を与えていただきます。内容は次の 2 つです。

1. 提供分を複製・改変・配布・公衆送信すること
2. **提供分を AGPL-3.0 以外の条件でもライセンスすること**（デュアルライセンス）

## 3. なぜ 2-2 が必要か

本体は AGPL-3.0 で公開しています。AGPL だけで受け入れると、提供分は AGPL に固定され、
**ソースを開けられない相手へ商用ライセンスを売る道が閉じます**。これは開発費を賄うための
経路なので、閉じると開発が続きません。

**この同意は遡って取れません。** 1 件でも CLA 無しに取り込むと、その部分について道が閉じます。

## 4. あなたの表明

- 提供分はあなた自身が書いたものであるか、そうする権利を持っていること
- 第三者の権利を侵害しないこと
- 勤務先などに権利が帰属する場合、必要な許可を得ていること

## 5. 保証しないこと

提供分は現状のまま受け取ります。あなたは提供分について、明示・黙示を問わず保証を負いません。
