# 画面の在り処

`docs/ui-direction.md` の**面**（S-1 …）が、実際にどの URL で開くか。
確認バッチの手順書（`scripts/verify_checklist.py`）が、この表を読んで問いに「画面: …」を添える。

**行き先の決まりは `web/src/Root.tsx` が持つ**（ST16 / design D8、ST19 / design D9）。
この表はそれを人が読める形に写したもので、**推測は足さない**。画面を足す Story は、この表に 1 行足す。

URL は `run.sh` が出す画面（既定 `http://127.0.0.1:5180`）からの相対。
スマホから見るなら `http://<手元の網のホスト名>:5180` に読み替える（`.env` の `ALLOWED_HOSTS`）
（**IP ではなくホスト名**。`tailscale serve` はホスト名で振り分けるので、IP 宛は tailscale が 404 を返す）。

| 画面 | URL | 行き方 |
|---|---|---|
| S-1 稼働状況 | `/` | 画面を開いた最初の状態。まだ入口の付け替え（ST25）をしていないので、ここがルート |
| S-2 主表現（1 日を見る） | `/#/day/2026-09-07` | アドレスの `#/day/<YYYY-MM-DD>` を書き換える。日付を省く（`#/day/`）と今日 |
| S-6 マスタ管理 | `/#/master` | アドレスに `#/master` を足す |

まだ実装が無い面（S-3 主観入力 / S-4 検索 / S-5 記録の詳細 / S-7 設定）は、作った Story が行を足す。
