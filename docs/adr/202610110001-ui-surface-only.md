# 画面の作り直しは見た目（表面）だけにし、骨格は変えない

- 日付: 2026-10-11
- 状態: 採用
- 出所: メモリ lint-purity-ui-refresh-plan.md

## 背景

画面の見た目を YAMAP 風にしたいという話があった。
画面の骨格は 2026-09-08 に決めている。時系列が主役で、リストと滞在の単位で並べる。

## 決定

YAMAP 風にするのは、本体の画面の見た目（表面）だけとする。骨格は 2026-09-08 の決定のまま変えない。
取り入れる YAMAP の良いところは「明るく親しみやすい見た目」である。

## 退けた案

- 地図が主役・カード・写真が主役の構成。選ばれていない。

## 反転の条件

記録なし。

## 影響

- 表面の playground は、走っている Story を待たずに進めてよい。
- 画面の表面の直しは change として流す。
