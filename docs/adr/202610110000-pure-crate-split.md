# 純粋な計算は I/O を持たない crate に分け、コンパイラで止める

- 日付: 2026-10-11
- 状態: 採用
- 出所: メモリ lint-purity-ui-refresh-plan.md・`docs/audit/2026-10-11-pure-crate-plan.md`

## 背景

「純粋関数で書く」は散文の規約で、守られているかを機械が見ていなかった。
サーバの計算は、DB や時計を使うコードと同じモジュールに混ざっているものがある。
一方で、走っている ST12・ST21 がサーバの広い範囲を触っていた。

## 決定

計算を I/O の依存を持たない crate に分ける。DB・tokio・ファイル・時計などの依存を持たせず、コンパイラで止める。
実施は ST12・ST21 の merge 後に 1 本の fix で行う。PC の収集アプリ側は ST08 の merge 後に 2 本目とする。

## 退けた案

- 検査スクリプトで純粋さを見る。

## 反転の条件

記録なし。
