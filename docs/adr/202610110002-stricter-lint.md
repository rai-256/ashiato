# lint を一段厳しくする（Rust は pedantic、Web は strictTypeChecked、Kotlin は baseline）

- 日付: 2026-10-11
- 状態: 採用
- 出所: メモリ lint-purity-ui-refresh-plan.md・`Cargo.toml`・`web/eslint.config.js`

## 背景

本人が「lint を厳しく」と求めた。main（4f170499）で測ると、Rust の pedantic で 551 件、Web の strict で 235 件の違反があった。
走っている ST12・ST21 がサーバと画面を広く触っていた。全体の違反を今直すと衝突する。

## 決定

- Rust: clippy の pedantic を止める。他人に配るライブラリ向けの文書の催促の 4 種は外す。
- Web: typescript-eslint の strictTypeChecked にする。
- Kotlin: detekt と ktlint を baseline 付きで入れる。
- 全体の違反の修正は、ST12・ST21 の merge 後に crate の分割と同じ fix で行う。Kotlin の baseline はいま進めてよい。

## 退けた案

記録なし。

## 反転の条件

記録なし。

## 影響

- `Cargo.toml` と `web/eslint.config.js` には、「まだ直していないだけ」の規則を許す表がある。全体の修正でこれを空にする。
- 全体の修正も change として流す（harness2 の ADR「要件から来ない作業は change として Story と同じグラフに流す」）。
- CI の Rust は stable を追うので、版が上がると pedantic の規則が増えて落ちうる。2026-10-12 に 1.99 で増えた 1 つを表に足した。
