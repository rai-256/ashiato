## 2026-10-13-st33-merge-consistency.md C4 — 分けた論理ソースが、滞在の削除の連鎖（FR-50）から漏れないようにする

- 何を: FR-50 の連鎖が見る項目のソースは固定の並び（`ITEM_SOURCES`）と `c03-myactivity-` の前置きだけ。「その他」や新しい検索・視聴の論理ソースを

- 失われるもの: 漏れれば、消した場面のその時いた位置が原文に残り、読み出し・書き出しへ流れ得る（外へ出たら戻らない）

## st14-outage-alert D20 — 正典 `external-ingestion` の「60 日を過ぎたことを知らせるのは ST14」を、通知の 75 日に合わせる

- **何を**: 正典 `openspec/specs/external-ingestion/spec.md` の Requirement「稼働状況の画面に書庫のソースの格子と最終日と直近に置いた書庫が出る」の
  「60 日を過ぎたことを知らせるのは ST14 で、この画面は見えるだけ（格子では、記録の間が 60 日を超えた日が『途絶』として見える）」（:697）と、
  Requirement「取り込み器は自分の論理ソースに 1 日 1 回の生存信号を送る」の「FR-35 の通知も鳴らない —— 60 日の想定間隔（第 1 回 Q7）が効かなくなる」（:588）は、
  FR-35 ★ 2026-10-13（ST14 の深掘り Q9 / Q3）と食い違う。通知は**最後の書庫の作られた時刻から 75 日**（登録簿の通知までの日数）、格子の「途絶」は今までどおり**最後の記録から 60 日**で、2 つは測り方が違う
- **なぜ ST14 で直さないか**: ST47 が `external-ingestion` を上流で触っている。同じ capability を 2 本が同時に触らない（admission の規則）。
  ST14 は `collection-coverage` の側に Requirement「書庫のソースは最後の書庫から登録簿の日数で途切れとする」を置いた
- **直し方の候補**: ST47 が `external-ingestion` を MODIFIED にするとき、2 つの文の「60 日」を「格子は 60 日、通知は最後の書庫から 75 日（`collection-coverage`）」に直す。
  文の直しだけで、Scenario（`書き出しを忘れると書庫のソースは途絶になる` は格子の話で、そのまま成り立つ）と振る舞いは変わらない
- **失われるもの（A）は無い**: 正典の理由の文の食い違いで、判定はどちらの文にも依らない
- **根拠**: openspec/changes/st14-outage-alert/design.md D20 / docs/audit/2026-10-13-st14-consistency.md C5

## st14-outage-alert R17 — 書庫のソースの格子の並びの条項に、集計の格子が Must と書庫の間に入ることを書き足す

- **何を**: 正典 `external-ingestion` の「書庫のソースの格子を、Must の 5 ソースより後ろ、退役したソースより前に置く」（:676）と Scenario「書庫のソースは Must の後ろで退役の前に並ぶ」（:709-712。「上から Must の 5 ソース・書庫のソース・退役したソースの順」）に、
  ST14 が `collection-coverage` に足すアプリ利用の集計（`c01-app-usage-rollup`）の格子が **Must の 5 ソースと書庫のソースの間**に入る（ST14 の design D10（仮））ことが書かれていない
- **なぜ ST14 で直さないか**: 上の D20 と同じ（ST47 が `external-ingestion` を触っている）。いまの画面の並び（`archives.ts` の `orderCoverageWithArchives`）と `archive-order.test.tsx` は集計を入れても壊れず、食い違うのは正典の文だけ
- **直し方の候補**: ST47 が `external-ingestion` を MODIFIED にするとき、並びの文と Scenario に「Must の 5 ソース・集計・書庫のソース・退役したソース」と書き足す
- **失われるもの（A）は無い**
- **根拠**: openspec/changes/st14-outage-alert/review/spec.md R17 / design.md D10（仮）
