# ST57 への申し送り

## ST55 D14 — 更新係が読む配置の正本

サービス名、サービスアカウント、プログラムの置き場、状態の置き場、DB とサーバの番号、取り込み待ちの並びは `crates/installer/src/layout.rs` の 1 か所を正本にします。正式版は `ashiato-db` / `ashiato-server`、開発版は `ashiato-db-dev` / `ashiato-server-dev` です。

更新係の置き場を足すときも、`C:\Program Files\ashiato`（開発版は `ashiato-dev`）と `C:\ProgramData\ashiato`（開発版は `ashiato-dev`）の列を崩さず、`db\17`、`media`、`export`、`backups\pre-migrate`、`archive-copies`、`logs\db`、`logs\server`、`settings` を状態の配下に置きます。更新の走らせ直しでは、旧サービスを止め、同じレイアウトを選んでからインストールを実行してください。
