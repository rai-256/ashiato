## ST57 C10 — Linux の更新係の起こし方

Linux の更新係は、配布物に含まれる `ashiato-updater` をサービスとして起こす。インストール後に `ashiato-updater service` を実行し、起動できたことを `systemctl status ashiato-updater` で確かめる。1 回だけ確認する場合は `ashiato-updater once` を使う。状態と確かめた記録は、サービスの設定で指定した更新係の置き場に残す。
