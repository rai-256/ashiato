## ST57 C10 — Linux の更新係の起こし方

この Story では Linux の配布物の中身を変えないため、Linux の配布物には `ashiato-updater` も systemd の unit もまだありません。Linux の更新係を配布物へ入れ、サービスとして起こす手順（`ashiato-updater service`、`systemctl status ashiato-updater`、1 回だけ確認する `ashiato-updater once`、状態と確かめた記録の置き場）は、Linux の入れ方を持つ Story（FR-131）で定めます。

## ST58 D8 — Linux のサーバの更新と戻し

ST58 は Windows のサーバの更新の手順（入っている版と違う版のインストーラで更新・移行が落ちたら退避から戻して前の版で起こし直す・途中で止まったら前の版へ戻し終えてからやり直す）だけを作る。Linux のサーバの更新と戻し（FR-114・FR-119・FR-120）も、Linux の入れ方を持つ Story（FR-131）で扱う。手順の段・印・戻す退避の特定（回ごとの空の置き場）・更新の記録の形は ST58 の正典（`openspec/specs/distribution/spec.md`）と design D1〜D3・D14（仮）・D20（仮）にそろえる。
