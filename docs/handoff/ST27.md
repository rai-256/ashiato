# ST27 への申し送り

ST27（AI（外部 AI・ローカル AI の 2 つの衛星）から MCP で問い合わせる）は、この申し送りを書いた時点（2026-10-11）では上流が始まっていない。
**差し戻しではない** —— 整合の確認（`docs/audit/2026-10-11-license-consistency.md`）の C3 を、ST27 の上流が深掘りの前に読めるように置いておく。

## C3 — AI の衛星が使う MCP は、版と契約（FR-89 / FR-95 / FR-103）の対象か

- 何を: MCP の道具（tool）の名前・引数・返す形を、衛星向けの API の契約と同じく版を付けて守るか（FR-89 / FR-95）、Apache-2.0 の契約として公開するか（FR-103）を決める。
  決めるのは ST27 の上流（計算し直せる B 段なら仮で、MCP の利用者が外にいて壊すと困るなら本人に問う）
- なぜ: AI は衛星の 1 つ（FR-59）なのに、FR-89 / FR-95 / FR-103 は「衛星が使う API」と書くだけで、MCP がそれに入るかを書いていない。ST42 も ST27 も触れていない
- 気をつけること: MCP の道具の定義は OpenAPI ではない。入れるなら ST42 の契約の検査とは別の差分の見方が要る
- 根拠: docs/audit/2026-10-11-license-consistency.md C3 / docs/requirements.md FR-59 / FR-89 / FR-103
