# ST45 への申し送り

## docs/audit/2026-10-12-st17-consistency.md C2 — ST17 の主観の口（`/feelings` `/feelings/reminder`）を読み出しの門に通す

- **何を**: ST17 は主観の読み出し `GET /feelings`（尺度・ひとこと・記入の日時）と通知の判断 `GET /feelings/reminder` を足す。spec は呼び出し元を
  「資格情報を持つ呼び出し元」とし、感度で絞らずに返すと書いている（2026-10-07。衛星の資格情報が無かった時点の文）。
  改訂後の要件では、主観は「外部 AI」の衛星に承認されず（FR-88 の表・PERM-4）、印の付いた記録はどの承認でも返らない（PERM-15）
- **ST45 で門を作るとき**: この 2 つの口も門の内側に入れる（衛星の資格情報では、承認された種類「主観」と印の無い記録だけ）。
  ST17 が先に archive されていれば、正典 `subjective-log` の「資格情報を持つ呼び出し元に返す」を ST45 が MODIFIED する —— そのとき INDEX の capability の表の `subjective-log` に ST45 を足す
- **それまで**: ST29 が「衛星の資格情報ではどの口も返さない」を全 route で守る（`docs/handoff/ST29.md` の C2）ので、ST45 の前に主観が衛星へ出る経路は無い。**失われるもの（A）は無い**

## docs/audit/2026-10-17-st09-consistency.md C2 — 消した滞在の時間の写真と画像の撮影位置を、衛星と AI に渡さない

- **何を**: ST09 の深掘り Q16 で、滞在を消しても写真と画像の記録には削除の印を付けない（FR-50 の★ 2026-10-17）。写真・写真の位置はローカル AI に承認されている（FR-88 の表・PERM-6）ので、
  削除の印と「出さない」の印（PERM-15）だけで絞ると、消した場面の撮影位置つきの写真が衛星と AI へ渡る
- **ST45 で門を作るとき**: 消した滞在の時間に入る写真と画像（`c01-photo` と ST09 が足す画像のソース）からは撮影位置（解析した値の欄・原文の EXIF）を抜いて渡す（FR-50 の★ 2026-10-17 の既定。書き出し NFR-16 と同じ厳しい側）。
  「写真は承認・位置は不承認の衛星には撮影地を抜いて渡す」（FR-88 の★ 2026-10-11）と同じ抜き方で、記録は書き換えない
- **それまで**: ST29 が衛星の資格情報ではどの口も返さないので、ST45 の前に写真が衛星へ出る経路は無い。**失われるもの（A）は無い**
