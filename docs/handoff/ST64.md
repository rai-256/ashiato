# ST64 への申し送り

## st61-auto-version-bump R9 — 版の検査は、番号の形の版番号を誰からでも受け取る

ST61 の版の検査は、左の数字（`tools/release/MAJOR`）が合えば、番号の形の版番号（`0.2.5` など）を組み立てる木を問わずに受け取る（組み立ては番号の印 `build-*` を見ない）。
CI の配る形の組み立ての job が番号を渡さないことは ST61 が検査で固定するが、手元で `ASHIATO_BUILD_VERSION=0.2.5` を渡せば、番号 0.2.5 を名乗る別の中身を組める（2026-11-19 の事故と同じ形）。
入れる側で、札を一度も付けていない組み立てを正式版の系統の上に入れない守り（FR-136）がこれを受ける。番号の記録（印 `build-<番号>` と、下書きの説明文の `ashiato-build: <番号> <commit>`）を照らせば、名乗った番号の commit と組み立ての印の commit が違うことも分かる。

携帯の PR の組み立ての APK は versionCode 1（`0.0.1`）になり、本人の携帯の 0.1.x（10,099・10,199）の上に上書きで入らない（ST61 design D6（仮）。review/spec.md R13）。
