## st17-daily-feeling R18 — 紐づけ先の種類は、登録簿の行とコードの検査を同じ change で足す

- **何を**: ST17 は紐づけ先の種類の登録簿 `core.feeling_target_kind`（day one は `day` と `stay`。追記のみ）を作り、
  取り込み口は「登録簿に行があり、かつコードがその種類の検査を持つ」ときだけ受ける（design D5 / D15）。
  新しい種類を足すときは、表の行と `feelings.rs` の検査（鍵の形・出来事の時刻の決め方・その種類の「終わり」—— 前/後の計算に要る）を同じ change で足す
- **既存の行は触らない**: 主観の行から登録簿へ外部キーは張っていない（鍵ではなく索引。FR-38）
- **根拠**: openspec/changes/st17-daily-feeling/review/spec.md R18 / design.md D5 / D15
