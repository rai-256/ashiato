# ST50 への申し送り

## st49-record-component-version D3（仮）・Risks — 版の脱落する間は、期限の後に FR-125 / FR-130 で止める
- 何を: ST49 は、収集アプリが送る 1 件ごとに `client_version`（作った部品の版）を足す。ST49 より前の S-01 は `client_version` を読み飛ばす
  （記録は 200 で入り、版だけが落ちる）。ST49 より前の版の収集アプリへ戻した間は、その版が欄を知らないので、やはり版が落ちる。
  この古い組み合わせを、期限（扉 32）の後は ST50 の送信契約の版（FR-125 / FR-130）で止める
- なぜ今入れないか: ST49 は送信契約の版を作らない（D18）。版を持たずに入った行には後から版を足せないが、本人の環境では S-01 を先に入れ替える順（D3）で脱落を最小にしている
- いつ・どこで: ST50 の深掘りで。古い組み合わせを止める期限と、止めるときの契約の版の規則を決める
- 根拠: openspec/changes/st49-record-component-version/design.md D3（仮）・Risks
