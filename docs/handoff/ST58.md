# ST58 への申し送り

## st48-db-version-guard R21 — 終了コード 3 は「移行の失敗」ではない（この回の退避は無い）

- ST48 の `ashiato-server migrate` は、DB に自分の知らない版が当たっている（`kind=db_ahead`）・版の記録を読めない（`kind=ledger_unreadable`）とき、
  **退避を取らず・DB に何も書かずに終了コード 3** で止まる（`openspec/changes/st48-db-version-guard/design.md` D4・D6。試験 `st48_migrate_refusal_takes_no_backup`）。
  標準エラーの 1 行目は `error: kind=<種別>`、続く `  db: <名前> (<版番号> <commit>)` は 1 版 1 行（20 件を超えた分は `  more: <N>`）、`  self: <版番号> <commit>`
- 終了コード 1 は移行の失敗（版の中身が当たらない・退避の失敗・接続できない）。こちらはその回の退避がある（退避の失敗なら当てていない）
- **rc≠0 を一律に「移行の失敗」と扱って退避から戻すと、終了コード 3 の回は退避が無いので、前の回の退避（それ以後の記録を含まない）を戻しうる** ——
  捨てたものは復元できない。FR-119 の戻しは終了コード 1 の回だけにし、終了コード 3 の回は**退避から戻さず**、前の版のまま起動し直す
- ST48 の起動の検査は起動のときだけ（`startup_refusal`）。動いている古い S-01 は、別の組み立てが DB を新しくしても止まらない。
  **更新の手順は、新しい版の migrate の前に古い S-01 を止める**
- 出所: `openspec/changes/st48-db-version-guard/review/code.md` R21（code-verify の手 6）
