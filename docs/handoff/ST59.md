# ST59 への申し送り

## st56-collector-connection-setup R0 — 合言葉の入れ直しの口と、値を変えた後の知らせは ST56 が作る（2026-11-04、ST56 の上流 spec。第 1 回の推奨で先に書いた版）

- **合言葉の入れ直し**: ST56 は `POST /collector-setup`（画面の「収集アプリの設定」）で、ログインの印に加えて画面の合言葉を入れ直させる（ST56 design D8・D22（仮））。照合はログインと同じ関数・同じ失敗の遅れ・同じ回数の制限の数え。
  FR-133 の「変えるときは今の画面の合言葉を入れ直させる」は同じ形で作れる。数えを別にするなら ST56 の D22（仮）の反転条件に当たる
- **値を変えた後**: 収集アプリの共有の値を変えると、携帯と PC は 401 で断られ、1 時間続くと「サーバに断られています。資格情報か送り先が違います。設定し直してください」と知らせる（ST56 design D12）。記録は捨てない（携帯は保持の上限 FR-8 まで）。
  変える画面は、変えた後に「収集アプリの設定」で新しい文字列を出して全部の収集アプリに貼り直す、と案内する（手順は `docs/collector-setup.md`）
