# ST10 への申し送り

ST10（原本と記録の週次の突き合わせ）は、この申し送りを書いた時点（2026-10-17）では change が無い（上流の前）。差し戻しではない。

## docs/audit/2026-10-17-st09-consistency.md C9 — 原本の欠け・送信待ち・動画を「不一致」に数えない

- **何を**: ST09 では、内容ハッシュを持つのに D-02 にファイルが無い記録が正常に残る —— (1) 送る前に端末から消えた原本（「原本の欠け」として件数で残す。ST09 deep.md の C8）、
  (2) 初回の過去ぶんの Wi-Fi 待ち（数日かかりうる。Q9）、(3) 動画（原本を送らない。FR-6）。また (4) 同じ写真の編集の後の版は別の原本になる（Q7）
- **ST10 の上流で**: 週次の突き合わせ（FR-72）が (1)〜(3) を「不一致」として毎週出さないように分ける（報告済みの欠け・送信待ち・原本を持たないソース）。
  手で消した D-02 のファイル（完了の判定）とは別に数える。突き合わせは C2 / C3 / C17 の内容ハッシュ（ファイル全体のバイトの SHA-256）を使う
- **失われるもの**: 無い（報告の分け方は後から変えられる）
