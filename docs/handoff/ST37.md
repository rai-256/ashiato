# ST37 への申し送り

## docs/audit/2026-10-12-st17-consistency.md C5 — ST17 の口も利用者識別子を引数から取っている

- **何を**: ST17 の design D8 / D9（2026-10-07。PERM-1 ★ 2026-10-11 より前）は `GET /feelings?…&user_id=`・`POST /feelings/reminder`（`{user_id?, at}`）・
  `GET /feelings/reminder?date=…&user_id=` と、ほかの読み出しと同じく `user_id` を引数から取る（省けば nil UUID）。
  ST37 の壊してはいけないもの（走っている ST21 / ST25 の口）に **ST17 の 3 つの口**も入れ、完了の判定「既存の口は利用者識別子を引数から取らない」の対象に数える
- **捕まえ方**: `docs/openapi.json` の params に `user_id` を持つ口を数えて 0 本を完了の判定にすれば、ST37 の着手の後に入った口も拾える
- **失われるもの（A）は無い**: 利用者は 1 人（nil UUID）で、口の引数を変えれば戻る
