# ST46 への申し送り

## st49-record-component-version 整合の確認 C5 — 衛星が書く行に、書いた S-01 の版（`server_version`）を持たせる

- **何を**: FR-123（2026-10-25 の本文。ST49 の深掘り Q2）で、S-01 が D-01 に書く衛星の記録も、書いた時点の S-01 の版（`crate::BUILD_STAMP`）を持つ。衛星自身の版は持たせない（サーバが確かめられない。衛星との契約は API の版 FR-89）。
  衛星の都合のデータの保管場所（FR-87）は `core.event` の外の新しい表になる。その表に `server_version text NULL` を持たせ、INSERT が入れる。
- **なぜ今直さないか**: ST49 は `core.event` と、いまある部品の追記のみの台帳に列を足す（design D7 / D10）。ST46 の表はまだ無く、ST49 の機械の止め（`st49_ledger_inserts_name_server_version`）は列を持つ表しか見ないので、列の無い新しい表を作っても落ちない
- **根拠**: `docs/audit/2026-10-25-st49-consistency.md` の C5、docs/requirements.md FR-123、openspec/changes/st49-record-component-version/design.md D10
