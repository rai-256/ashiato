# ST52 への申し送り

## ST48 の上流（2026-10-25）から: 配った印のタグの型

- ST48 は「配った移行は名前も中身も変えられない」を、リリースのタグ `v[0-9]*` の版にある移行と今の木を比べて CI で止める（`tools/check-released-migrations.sh`。`openspec/changes/st48-db-version-guard/design.md` D9）
- ST52 がリリースのタグを別の型にするなら、この台本の型を一緒に変える。タグが 1 つも無い間は何も凍結しない
- ST48 は版の記録に組み立ての版番号（`CARGO_PKG_VERSION`）と commit（`ASHIATO_BUILD_COMMIT` → `git rev-parse HEAD`）を残す（D8）。版番号の出所を 1 つにしたら、そこから読むように替える

## st49-record-component-version（2026-10-28）から: 組み立ての印の版番号
- ST49 は記録に残す版を `<版番号>+<commit 40 桁>[.dirty][.debug]` の印にし、`crates/build-stamp`・`collector-android/app/build.gradle.kts`・`web/build-stamp.ts` が組み立てる。
  ここの版番号は今、それぞれの出所（`CARGO_PKG_VERSION` など）から読んでいる
- 版番号の出所を 1 つにしたら、3 か所の版番号をそこから読むように替える。commit は ST48 と同じ値（`ASHIATO_BUILD_COMMIT` → `git rev-parse HEAD`）を使い、別の出所にしない
- 根拠: openspec/changes/st49-record-component-version/design.md D5・D10
