# ST62 への申し送り

## st61-auto-version-bump R3 — 番号の組み立ての消し方と、番号の印 build-* の守り

ST61 は番号を付けた組み立てを、番号ごとに配布元の下書きのリリース（印 `build-<番号>`）に**全部残す**（ST61 design D1（仮）。月に約 1.7 GB）。
消し方（何日・何個を残すか、札を付けた番号を残すか）は決めていない。CI の成果物と違って期限で消えないので、置き場の上限に当たる前に、札を作るこの Story で決める。

番号の記録は印 `build-<番号>`（ST61 design D7）。配った印 `v*` の規則（消せず動かせない）は `build-*` に掛かっていない。印を消すか動かすと、番号と中身の対応が崩れる（ST61 の番号付けは「印が別の commit を指せば止まる」で気づくだけ）。札の規則と一緒に `build-*` も守る。

番号ごとに、debug の鍵で署名した APK と、署名していない APK `ashiato-collector-<番号>-unsigned.apk` が並ぶ（ST61 design D2（仮））。正式な鍵の署名を札のときに足すなら、署名していない方に足す。

## st61-auto-version-bump R12 — 急ぎの直しの未決は開いたまま

ST61 は、番号が main にだけ付くので、正典から「緊急の修正の枝」を外した（REMOVED）。FR-105 の未決「急ぎの直しの出し方（main に merge して進んだ番号へ正式版の札を動かすか、正式版の番号から別の道を作るか）」は決めていない。
ST61 から ST62 までの間の手順は「main で直して次の番号を出す」。別の道を作るなら、その道の commit にどう番号を付けるか（main の番号と重ならない形）も一緒に決める。
